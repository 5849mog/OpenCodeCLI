## 测试结论

**（部署后填写）**

### ✅ 说明

- `sqrt` 等数学内建是 **POSIX awk 自带**（One True Awk 经 `-lm` 链接），与 bc/gawk 一致；
  `sqrt(9)` → `3`。原 JS 实现不支持是因为它压根没有算术求值器。
- 本地 `bun dev`（未装 emsdk）时 awk 走 JS 降级实现，以上矩阵反映的是 **部署版（CI 构建的
  wasm）** 的行为。
- wasm 不可用时 `console.warn("[awk-wasm] init failed, using JS fallback: …")` 且回退旧行为。
