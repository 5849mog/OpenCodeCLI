# 《暴雨》· 风格规格书

**一句话**：一场雨，就是一部六幕的黑色电影。

## 场合与效果

**展映**——屏幕上放给人看效果，没有人在现场讲解。这一条决定了全片的动画纪律：
**节拍数量、单页动画条数、单条时长都不受约束**（那些阈值的前提是"有人在台上讲、观众要点鼠标"）。
整页自动播完、一页多组、长动画、组合动效都是刻意要的。

## 风格

**黑色电影海报（Film Noir）**——1940–50 年代黑色电影纸质海报排印：墨黑、强对比、硬边光带、奶油白与海报黄的排印。

**效果承诺**：眼前一亮 · 戏剧性。夜雨配黑色电影是天然一体的：它的"硬边对角光带"正好可以当雨光与闪电。

**用色纪律**（必守）

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `0E0D0C` | 墨黑底，占 65–75% |
| PANEL | `1C1A17` | 次级面（水面、远山剪影），只能是底色提亮 |
| TEXT | `F5EDDC` | 奶油白：文字、雨丝、地平线 |
| MUTED | `A79C86` | 次级文字（时间戳、小字） |
| ACCENT | `E3B341` | 海报黄，≤5%，**只给"光"这一类元素** |

**禁止项**（本风格的定义性特征，不是可选项）：柔光、发光、渐变、圆角、金色/铜色金属感、第二个强调色。
**光的边界一律是硬的**——街灯靠"切掉光带"被看见（剪影），不靠发光；"光晕"由一粒粒被灯照亮的雨点构成。
强调色只允许出现在"光"上：灯泡、灯在水面的倒影、被灯照亮的雨点、穿过灯光的那一滴雨、水花。

**字体**：宋体（标题）+ 微软雅黑（小字）+ Georgia（时间戳）
**字号体系**：主标 54 / 片名 84 / 时间戳 26 / 小字 14

**视觉母题**（每页复现，但版式不重复）：硬边对角光带（斜切画面，与雨的斜向同向）+ 街灯剪影 + 雨丝纹理 + 一处暖色

**隐藏时间线**：每页一个时刻，串起来是同一个傍晚的一场雨（18:40 → 19:20）。

|---|---|---|---|---|---|---|---|
| P1 | 立论 | 雨还没来 | 单点聚焦 | 空街、街灯、干地 | 大数字 18:40 | 18:40 | 3 拍 · 几乎不动（蓄力，"没有动"本身就是内容） |
| P2 | 举证 | 风比雨先到 | 通栏推移 | 从两侧压过来的云 | 流程示意（风的动线） | 18:47 | 4 拍 · 全片最长动线，云走弧线 |
| P3 | 转折 | 雨是从一滴开始的 | 满幅雨幕 + 左下角标 | 第一滴（暖色实心雨丝） | 纹理（雨幕） | 18:52 | **6 拍 · 9.6s（已做，见下）** |

**结构性例外（明说，不当疏漏）**：
- P6 是**片名卡**，不是判断句内容页。预告片的语法就是"先给六个镜头，最后才打片名"——所以全片的标题在最后一页，封面页刻意不做片名。
- 全片 **0 次点击**：每一页的动画都自动播完，你要做的只有翻页。

## 动画档位

**没人现场讲（炫技/展映）** → 节拍约束整类豁免。

**明知而保留的告警**（qa 会报，我不会为了让它闭嘴而改弱）：
- P3 一页 **6 个揭示节拍**（qa 建议 ≤4）
- P3 一页 **71 条对象动画**（qa 建议 ≤8）

这两条正是你要的"多和密"。qa 自己的报告里就写了「炫技/展映档可明知而保留」。

## 菜单外的写法（你说同意的那种更底层的方式）

菜单里的 7 种效果只能：**同时起** 或 **严格串行**；切换有 4 种（含 morph）。做不到的三件事：

| 想做的 | 为什么菜单做不到 | 用到的底层手法 |
|---|---|---|
| P2 云沿弧线掠过 | 菜单的「飞入」只能从画布边缘走直线 | 沿路径移动 `p:animMotion` |
| P4 闪电余晖闪三下 | 菜单 7 种效果都只播一次，没有"重复" | 重复脉冲 `repeatCount` |
| P5 光柱缓慢旋转 | 菜单完全没有旋转 | 旋转 `p:animRot` |

**依据**：手法库里这三种都有现场采样依据（`p:animMotion` 1 处、`p:animRot` 2 处、`repeatCount` 有前一份交付的实测先例）。**但这几个采样都没有做过往返验证**，所以动手前我会先跑一轮 COM 探针，让 PowerPoint 自己生成一份权威编码再抄；探针失败就退回菜单方案，并告诉你哪一页退化了。

**没法自动检查的部分（先声明）**：手写动画默认只验"文件能打开 + 读回条数"。我会给每一页附一份**断言清单**（形状 / presetID / 起始ms / 时长ms / 重复 / 参数，覆盖该页全部效果），把逐条核对补回来——附了断言就不算检查降级。
**但仍有一条残余风险**：本机的 PowerPoint COM 被 WPS 兼容层接管（版本报 `12.x`），验证强度弱于真 PowerPoint。**最终请用真 PowerPoint（不是 WPS）播一遍。**

## 检查降级声明

- 无外部素材、无插图、无公式、无图标、无表格 → 这几类检查不适用（不是"跳过"）。
- 字体全部在跨平台安全名单内（宋体 / 微软雅黑 / Georgia，本机已确认存在）。
- 渲染走 WPS 兼容层，所以**预览图看不到动画**；动画由注入器的逐条断言 + PowerPoint 读回负责，PNG 由闸门二负责。
