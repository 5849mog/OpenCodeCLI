# learn-anything

一个知识学习类的框架 skill：让学习者真的学会一块知识，而不是听完觉得懂了。

适用于 ZCode / Claude Code 等支持 SKILL.md 约定的编码代理。

## 核心主张

**学会的唯一证据是学习者的产出。** 不是 AI 讲得清不清楚，也不是学习者说了「懂了」。

框架的设计原点是一个信息差：AI 要改变的是学习者脑子里的状态，而它看不见那个状态，只能看见对方的产出。所以整套流程的重心不在「怎么讲得漂亮」，而在「怎么逼出产出、并精准纠错」。头号禁令是「懂了吗？」→「懂了」→ 继续这种假验收。

## 几个关键机制

- **按知识类型路由**，不按主题。学「透视表怎么用」是技能类，学「为什么它比 SUMIF 快」是概念类，学快捷键是记忆类——三条路径的流程、产出任务、验收方式完全不同。
- **两道闸门抓不同的错**。每段的产出闸门抓「当场记住了没」，收尾的迁移闸门抓「换个场景还会不会用」。前者干净不代表后者能过。
- **迁移闸门派独立考官**，只给它能力目标和学习者的产出原文，**不给它 AI 的讲解稿**。教的人出题会不自觉只考自己讲过的角度，那是自我确认，测不出迁移。
- **回合停点纪律**。`AskUserQuestion` 这类选项工具会结束回合并占住用户的输入框，所以它和开放题永不同回合；产出要求一出口就必须停住等人。
- **内部件不给用户看**。掌握层级、施工图、闸门、教学法名称、以及「类比 / 失效」这类元词都是 AI 自己选路和自检用的，对用户只说动作：「你能自己上手做出来」而不是「目标 L4」。
- **施工图与开场说明耦合**。7 字段内部施工图是分段施工的依据，开场说明是它的机械投影——写不出开场说明，说明施工图没写。
- **长程落盘、单次不落盘**。速览和单元一次会话学完，什么都不写；长程写一份状态文件（`~/.learn-anything/sessions/<主题>.md`），记施工图、进度、逐段验收记录、产出原话和回顾题，下次新开对话说「继续学 X」即可直接读文件续上。

## 安装

放到任意一处技能目录下即可，保持 `learn-anything/` 这个目录名（必须与 `SKILL.md` 里的 `name` 一致）：

```
ZCode          ~/.agents/skills/learn-anything/     或  ~/.zcode/skills/learn-anything/
Claude Code    ~/.claude/skills/learn-anything/
```

目录结构必须是（本 README 不影响运行，可留可删）：

```
learn-anything/
├── SKILL.md
└── references/
    ├── questioning.md
    ├── phase-intake.md
    ├── phase-plan.md
    ├── phase-teach.md
    ├── phase-close.md
    ├── pitfalls.md
    └── methods/
        ├── route.md
        ├── t1-concept.md … t8-debate.md
        └── toolbox.md
```

新开一个会话才会被发现。之后说「我想学会 X」「讲讲什么是 X」这类话就会自动触发；只是查一个事实或要一段代码不会触发。

> 本目录在这个仓库里**仅作存档**，不参与站点构建（`/skills/` 被 .gitignore 排除，所以放在 `docs/` 下）。

## 已知取舍

**落盘边界按需**：速览和单元一次会话学完不写任何文件；只有长程写状态文件，因为长程必然跨会话，不落盘历史就断。

即使有状态文件，**跨天的间隔重复仍不能自动发生**——文件不会提醒任何人回来学，主动回来仍靠用户。间隔效应的抗衡手段是分布在多天的重取（Ebbinghaus），模型能做的只是每次续学开场用文件里的回顾题做检索练习，强度低于真正的间隔重复。这一点在 `SKILL.md` 与 `phase-close.md` 里有明确交代，没有假装它等价；记忆类知识尤其要在收尾说清（`methods/t3-memory.md`）。
