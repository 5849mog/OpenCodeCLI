# 出题地基 · 共享判据

> **何时读**：出任何题之前——诊断题（`phase-intake.md`）、变式题（`phase-teach.md`）、迁移题 / 考官题（`phase-close.md`）共用本文件的判据。速览不出题，不读本文件。

**一道题的价值等于它能区分出什么。** 所有人都答对或所有人都答错的题，信息量为零。好题的判据只有一条：**答对的人和答错的人，脑子里的差别是你想测的那个差别。**

## 三条通用规则

1. **测提取，不测识别。** 认得出（看到正确答案能选中）远比想得出（自己产出）容易。同一个知识点用选择题测，通过率能比开放题高一大截，而高出来的那部分是假的。
   - **默认用开放题。** 只有在需要快速定位误解、且已经知道有哪几种典型误解时才用选择题（此时错误选项本身是探针）。
   - **判断题几乎无用**，一半靠猜。要用就必须追问「为什么」。
2. **题干里不能含答案。** 最常见的形式是术语泄漏：问「rebase 的重放机制会导致什么？」——「重放」这个词已经把答案给了。改成「你 rebase 之后发现 commit 哈希全变了，为什么？」自查方法：**把题干里所有你刚讲过的关键术语划掉，题还问得成立吗？** 划掉就问不成立的题，测的是他记不记得你的用词，不是他懂不懂。
3. **别只考你讲过的角度。** 你讲解时用的例子、切入角度、措辞，会不自觉地成为你出题的默认框架。学习者在这个框架内答对，只证明他跟得上你，不证明他能独立使用。这条是**门二必须派独立考官**的全部理由（见 `phase-close.md`）。

## 出题翻车清单（出题前扫一眼）

| 症状 | 为什么坏 | 怎么改 |
|---|---|---|
| 题干里有刚讲过的术语 | 测的是记不记得措辞 | 划掉术语重写题干 |
| 五道题全是同一变式 | 表面练了五道，实际一道 | 每道换一个变式方向 |
| 难度全在同一档 | 全对或全错，零信息 | 铺开三档 |
| 用选择题验收掌握度 | 识别 ≠ 提取，系统性高估 | 默认开放题 |
| 只考讲过的角度 | 自我确认，测不出迁移 | 闸门二派独立考官 |
| 问「懂了吗」 | 这不是题 | 换成能判对错的动作 |
| 一次发十道题 | 他会挑简单的答，或者干脆放弃 | 3–5 道，闸门一每段一道 |
| 判对了就过，不追问理由 | 猜对和会做无法区分，L6 尤其致命 | 结论对也要追一句「为什么」 |
| 批改只给正确答案 | 错的模型还在，换个形式还错 | 归因到四类来源之一（见 `phase-teach.md` 批改节） |
| 反复纠同一点纠不动还继续纠 | 病根在更早的概念 | 停下回补前置 |
