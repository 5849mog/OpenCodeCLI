# 教学模式库

按知识类型选模式，不是按主题选。同一个「学 Excel」，学「透视表怎么用」是技能类，学「为什么它比 SUMIF 快」是概念类，学「快捷键」是记忆类——三条路径的流程、产出任务、验收方式全不一样。

---

## 一 · 教学法的来源（硬规则，先于一切）

**没有可指认来源的教学法，不许写进施工图。**

「循序渐进」「深入浅出」「由点到面」不是方法，是形容词。它们描述的是你希望达到的效果，不是你要执行的动作，所以无法执行、也无法判断有没有执行到位。

一个合格的教学法必须能说出三件事：**谁提出的 / 它的适用范围 / 它什么时候失效**。第三条最重要——所有教学法都有失效条件，不知道失效条件就会在错误的地方硬套。例如刻意练习需要即时反馈，没有反馈渠道的知识（比如「培养审美」）硬上刻意练习只会变成盲目重复。

本文件每条方法都标了来源和证据强度：

- **【实验证据强】** —— 有重复验证的实验研究支撑，可以放心当默认做法
- **【经验共识】** —— 教学实践中广泛认可，但缺少严格对照实验，用的时候留意个体差异

**这些方法名和来源是你选路、守纪律用的，不对用户说。** 他不需要知道你在用「刻意练习」还是「worked-example fading」，他只需要知道「我先带你做一遍，然后你自己做一遍」。对用户报方法名会让他觉得自己是实验对象——见 `pitfalls.md` 第 19 条。

## 二 · 先判知识类型

先问自己：**学会之后，他要做出什么动作？** 答案决定类型。

| 类型 | 学会后要做的动作 | 典型请求 | 走第几套 |
|---|---|---|---|
| 概念理论类 | 能解释、能判断某个说法对不对 | 什么是熵 / 通货膨胀怎么发生的 / attention 是什么 | 1 |
| 技能操作类 | 能亲手做出来 | 学会用 git rebase / 学会做红烧肉 / 学会剪视频 | 2 |
| 事实记忆类 | 能准确回忆出来 | 五十音 / 元素周期表 / 常用英语单词 / 法条 | 3 |
| 解题程序类 | 能独立解出同类题 | 学会解微分方程 / 学会做动态规划题 | 4 |
| 系统全局类 | 能在脑中定位任意局部 | 看懂一个陌生代码库 / 理解医保体系怎么运转 | 5 |
| 判断品味类 | 能分辨好坏并说出理由 | 学会看设计好不好 / 学会 review 代码 / 学会挑咖啡豆 | 6 |
| 语言类 | 能听说读写产出 | 学会某个语法点 / 提高口语 / 读懂学术英语 | 7 |
| 争议立场类 | 能重建各方论证并评估 | 搞懂核电到底该不该建 / 理解 AI 监管的争论 | 8 |

**判不准时的两个决断技巧：**

- **看他会怎么"用错"。** 概念类的典型错误是用在不该用的地方；技能类的典型错误是手生做不出来。他更怕哪种错，就是哪一类。
- **两类打平时问他一句，别自己框定。** 「学会看财报」框成「怕误读数字」是系统全局类（走地图），框成「怕看不出公司有问题」是判断品味类（走成对对比）——两条路径差异巨大，而决定权在他的真实用途上，不在你的框定习惯上。一句「你更怕看不懂，还是更怕被财报骗」就能定下来，比你猜准得多。
- **一个请求可以横跨两类，但要分段，不要混着教。** 「学会用 rebase」主体是技能类，但里面「为什么哈希会变」那一小段是概念类——那一段就切出来按第 1 套走，走完回到第 2 套。混着教的结果是既没讲透也没练熟。

## 三 · 八套教学模式

### 1. 概念理论类 —— ADEPT + 主线类比 + 反例边界

**承诺**：让他能把这个概念用自己的话讲给外行，并且知道它管到哪儿为止。

**适用**：熵、通胀、attention、期权 Greeks、递归、免疫应答——凡是「一个东西是什么、为什么这样」。

**忌用**：需要肌肉记忆的操作，和大量并列的事实。

**来源**：ADEPT 框架（Kalid Azad，BetterExplained）【经验共识】；类比迁移的结构映射理论（Dedre Gentner）【实验证据强】；概念转变模型（Posner 等，1982；物理教育研究里的迷思概念工作）【实验证据强】。

**流程**：

1. **A 类比（Analogy）** —— 先给一个他已经熟悉的东西。这一步是全套的地基：新概念必须挂在旧结构上，否则只能死记。**同时声明类比在哪里失效**，例：「把注意力想成在一堆文件里打分挑重点——但它不是真的『挑一个』，是按分数加权全都取一点，这是类比失效处。」
2. **D 图示（Diagram）** —— 画出来或用文字描述空间关系。语言和视觉走两条编码通道，双通道记得牢（双重编码，Allan Paivio）【实验证据强】。纯文字对话里就用结构化的文字图示，别省。
3. **E 例子（Example）** —— 一个具体到有数字的例子，走一遍。
4. **P 大白话（Plain English）** —— 不带任何术语讲一遍。这一步是给你自己的检查：讲不出大白话说明你也没通。
5. **T 技术定义（Technical definition）** —— **最后才给定义**。定义是压缩过的结论，放最前面等于让他背一串符号。放最后，定义就变成了「原来那句话就是这个意思」的确认。
6. **反例边界** —— 至少一个「看起来该用其实不该用」的例子。

**验收方式**：L2 用自己的话讲一遍 → L3 举一个你没给过的新例子 → L5 说出边界。**举新例子这一步不能省**，它是概念类唯一能区分「理解了结构」和「记住了你的例子」的测法。

**该类型的专属翻车**：中途换类比。第二个类比再妙也别换——学习者刚在第一个类比上建好结构，换一个等于推倒重建，净损失。要补充就在原类比上加细节。

### 2. 技能操作类 —— 最小可用闭环 → 刻意练习 → 撤脚手架

**承诺**：让他今天就能做出一个虽然简陋但完整可用的成品，然后逐步撤掉扶手。

**适用**：git 操作、做菜、剪视频、Excel、写测试、调试。

**忌用**：没有动手条件的场合（他现在没装 git、没有食材）——先解决动手条件，或改走概念类只讲原理，但要说明「这次只讲原理，你没练过就还不会」。

**来源**：刻意练习（K. Anders Ericsson）【实验证据强】；引导撤除效应 / guidance fading（Sweller 学派）【实验证据强】；最近发展区（Vygotsky）【经验共识】。

**流程**：

1. **先给最小可用闭环** —— 一条能跑通的最短路径，哪怕很丑。**不要先讲全部选项和参数。** 先有一次成功体验，后面所有细节才有地方挂。
2. **拆出一个具体动作反复练** —— 刻意练习的三个条件必须全有：难度略高于当前水平、每次有明确目标、**即时反馈**。缺反馈就不是刻意练习，只是重复。
3. **制造可控的失败** —— 主动让他撞一次典型错误（制造一次冲突、故意漏一个参数），在受控环境撞比在真项目撞便宜。
4. **撤脚手架** —— 第一次你带着做，第二次你只给提示，第三次他独立做。这个递减是刻意的：一直带着做会产生「跟着能做到 = 我会了」的错觉。
5. **给一个真实小任务收尾** —— 用他自己的真实场景，不是练习题。

**验收方式**：必须是 L4 动手做出来。**技能类不接受「讲一遍」当验收**——讲得出步骤和手能做出来是两件事，中间隔着无数细节。

**但你看不见他的终端和软件界面**，所以动手类的产出必须设计成**有可粘贴的证据**：让他贴回 `git log` 的输出、贴回报错原文、贴回结果截图。设计任务时就要想好「他交什么回来我才能判」——判不了的任务等于没有闸门。**这条要在开场说明里对他讲清**（施工图不发给用户，写在那儿他看不到），否则他做完只回一句「做好了」，你一样是盲的。

**该类型的专属翻车**：一次把所有选项讲全。参数手册式的讲解会让他在第一次动手时不知道从哪下手，因为你没给他一条默认路径。

### 3. 事实记忆类 —— 记忆术 + 检索练习

**承诺**：让他真的记住，而不是「学过」。

**适用**：五十音、单词、元素周期表、法条编号、快捷键、解剖名称。

**忌用**：有内在逻辑可推导的东西。能推导的别背——但要小心：**学习者常把「需要记」的和「能推导」的搞混**，先帮他分清哪些必须硬记（约定俗成的部分），哪些可以推（有规律的部分），这一步本身就能砍掉一半记忆量。

**来源**：间隔效应（Ebbinghaus，1885）【实验证据强】；测验效应 / 检索练习（Roediger & Karpicke，2006）【实验证据强】；关键词记忆法（Atkinson）【实验证据强】；古典位置记忆术 / 记忆宫殿【经验共识】。

**流程**：

1. **先分堆** —— 必须硬记的 / 有规律可推的 / 可以先不管的。
2. **给记忆钩子** —— 谐音、形状联想、词源拆解、编故事。钩子越荒诞越好记，这不是玩笑：情节化和异常性都能提升提取率。
3. **立刻检索，不要重读** —— 讲完马上盖住让他回忆。**重读的感觉比回忆舒服得多，但效果差得多**（这是流畅性错觉的经典案例）。宁可让他答错，答错后的纠正比顺畅重读记得牢。
4. **交错不同批次** —— 别一次只练一堆，混着抽（交错练习，Rohrer & Taylor）【实验证据强】。
5. **不完整的知识也要开始检索** —— 不用等「学完」才测。

**验收方式**：L1 能准确回忆即达标。这是唯一一类 L1 就算学会的知识。**但要闭卷回忆，不是认得出**——认得出（识别）远比想得出（提取）容易，用选择题验收会严重高估。

**该类型的专属翻车**：本技能不落盘，所以跨天的间隔重复无法自动执行。**要在施工图的「已知取舍」里明说**：记忆类知识不跨天重取一定会忘，会话内的练习只是开个头，后续得靠他自己或 Anki 这类工具。别让他以为一次会话就记住了。

### 4. 解题程序类 —— 例题 → 半填空 → 独立求解

**承诺**：让他能独立解出同类新题，而不是只看懂你的解法。

**适用**：数学题型、动态规划、电路分析、化学计量、财务计算。

**忌用**：开放性无标准答案的问题（那走判断品味类）。

**来源**：样例效应 / worked example effect（Sweller & Cooper，1985）【实验证据强】；完成问题效应 / completion problem（van Merriënboer）【实验证据强】；自我解释效应（Chi 等）【实验证据强】；交错练习（Rohrer & Taylor）【实验证据强】。

**流程**：

1. **完整例题，讲每一步的"为什么选它"** —— 关键不是步骤，是**每一步的决策依据**。「这里为什么用换元而不是分部？因为看到了这个特征」——这句才是可迁移的部分，步骤本身不可迁移。
2. **半填空** —— 同类题，你写出骨架挖掉关键步，让他填。这一步是纯增量，直接从例题跳到独立求解会让大部分人卡死在起步。
3. **独立求解一道同类题**。
4. **交错一道相邻题型** —— 混进一道需要判断「该用哪个方法」的题。**只练同一题型会让他练成条件反射，考试时题型一混就崩**——因为他从没练过「识别这是哪类题」这个动作，而那是真实场景里的第一步。
5. **让他自己解释为什么这么解**（自我解释），不只是给答案。

**验收方式**：L4 独立解出新题 + 能说出「看到什么特征所以选这个方法」。第二半不能省，只有答案对说明可能是套路对了。

**该类型的专属翻车**：给的练习题全是同一变式。表面看练了五道，实际只练了一道。

### 5. 系统全局类 —— 骨架先行，先地图后细节

**承诺**：让他拿到一张能定位任意局部的地图，之后自己钻哪儿都不会迷路。

**适用**：陌生代码库、一个行业怎么运转、医保 / 供应链 / 编译器 / 操作系统的整体图景。

**忌用**：单点概念（别把「什么是熵」做成一张知识地图，那是过度工程）。

**来源**：先行组织者 / advance organizer（David Ausubel）【实验证据强】；专家—新手差异研究（Chase & Simon 的棋手记忆实验，专家靠有意义的块而非更大的记忆容量）【实验证据强】。

**流程**：

1. **先给一句话的整体功能** —— 这个系统存在是为了解决什么问题。没有这句，所有细节都是孤立的。
2. **给 3–5 个主要部件和它们之间的数据 / 因果流向** —— 只到这个粒度，**先不进任何一个部件内部**。这是全套最难守的一步，因为讲到某个部件时你会本能地想展开。
3. **走一条端到端的路径** —— 挑一个最典型的输入，跟着它穿过整个系统。一条完整路径比五个孤立部件的详解有用得多。
4. **让他指位置** —— 给一个现象或一个文件名，让他说出「这属于哪个部件、在流程的哪一步」。这是本类型的核心验收动作。
5. **然后才按他的需要下钻**，一次只钻一个部件，钻完回到地图确认位置。

**验收方式**：L6 能定位和诊断——给一个陌生的局部（一个报错、一个文件、一个现象），他能说出它在系统里的位置和上下游。

**该类型的专属翻车**：从第一个部件开始深讲。这是最自然也最致命的顺序，因为他还没有挂载点，第一个部件的所有细节都会掉在地上；讲到第三个部件时，他已经忘了第一个。

### 6. 判断品味类 —— 成对对比 + 判据外显

**承诺**：让他从「说不出为什么但感觉不对」变成「能指出是哪一条不对」。

**适用**：看设计好坏、code review、辨别论文质量、品酒、判断文案。

**忌用**：有唯一正确答案的东西。

**来源**：类比与对比促进结构抽取（Gentner 的 case comparison 研究）【实验证据强】；知觉学习需要大量对比样例【实验证据强】；专家直觉的可解释化（Bjork 的合意困难思路）【经验共识】。

**流程**：

1. **成对给样例，只差一个维度** —— A 和 B 只在一处不同，问他哪个好、差在哪。**单个样例学不出判据**，判据是从差异里浮现的，这是本套的全部机理。
2. **他答完再给判据的名字** —— 顺序很重要：先让他自己感觉出差异，再给这个差异一个名字（「你说的『挤』，叫视觉密度失衡」）。反过来先给名字，他会变成套名词。
3. **加难度：给两个都不错的** —— 让他说出各自的取舍。品味的核心不是分好坏，是识别取舍。
4. **给一个反直觉案例** —— 一个违反常规规则但成立的例子，让他说出为什么这次能成立。这一步把规则变成判断，避免他学成教条。
5. **让他自己找一对样例来对比** —— 最强的验收。

**验收方式**：L5 能划界——看到一个案例，能指出用了什么、代价是什么、什么场景下这个选择就不成立。

**该类型的专属翻车**：给一堆规则条目让他记（「留白要够、对比要强、字体不超三种」）。规则背下来的结果是他会拿规则去套，套出一堆「符合规则但很难看」的东西——因为他从没练过判断规则该不该适用。

### 7. 语言类 —— 输入 → 聚焦注意 → 产出 → 纠错

**承诺**：让他能真的用出来，不只是认得。

**适用**：某个语法点、口语表达、学术英语阅读、写作句式。

**忌用**：语言学理论本身（那是概念类）。

**来源**：可理解输入 i+1（Krashen）【经验共识，有争议】；注意假说 / noticing（Richard Schmidt）【实验证据强】；输出假说（Merrill Swain）【实验证据强】；纠正性反馈研究【实验证据强】。

**流程**：

1. **给足量的真实输入**，难度略高于当前水平，但意思能猜出来。
2. **聚焦注意** —— 明确指出「注意这个结构」。**没有被注意到的输入不会变成习得**，这是 noticing 假说的核心，也是「看了很多美剧但口语没进步」的解释。
3. **要求产出** —— 让他用这个结构造句 / 说一段。产出会强迫他从「大概意思懂了」升级到「必须选一个具体形式」，这个压力是习得的关键推力。
4. **纠错要具体到规则** —— 不只是给正确说法，要指出他的错误来自哪条规则的误用（常见是母语迁移）。
5. **换情境再产出一次** —— 同一结构在不同话题里再用一次，防止和情境绑死。

**验收方式**：L4 能在新话题里正确产出。**认得出不算**，语言类里识别和产出的差距是最大的。

**该类型的专属翻车**：只讲规则不要产出。语法规则的清晰讲解会让人产生强烈的懂了感，而这种懂了和能不能说出来几乎无关。

### 8. 争议立场类 —— 多方论证重建 + 最强反驳

**承诺**：让他能公正重建各方论证，知道分歧的真正位置，而不是收集了一堆立场标签。

**适用**：核电、AI 监管、最低工资、某个技术选型之争、学术上未定论的问题。

**忌用**：有明确答案却被包装成争议的问题（例如已有充分共识的科学结论）。遇到这种要**明确说出「这个问题在专业领域并无实质争议」**，然后讲清共识和为什么公共讨论里看起来有争议——把伪争议当真争议教，是在制造错误的不确定感。

**来源**：《论自由》中「必须理解对立观点的最强形式」（John Stuart Mill）【经验共识】；Rapoport 的批评规则（经 Daniel Dennett 转述）【经验共识】；论证图式与批判性思维教学【经验共识】。

**流程**：

1. **先找分歧点，不要先讲立场** —— 大多数争议的实际分歧只在一两个具体位置上（对某个事实的估计不同 / 对某个价值的权重不同 / 对某个因果链的判断不同）。**先定位分歧点，整场争论就从一团乱麻变成几个具体问题。**
2. **每一方都用它的最强版本** —— 不是最容易反驳的版本。给稻草人立场是本类型的头号失败，因为它让学习者以为自己理解了对立面，实际只是学会了轻视它。
3. **区分三层**：事实分歧（可查证）/ 因果分歧（可论证）/ 价值分歧（不可裁决，只能明示）。价值分歧要坦白说「这一层没有正确答案，只能明确你自己的权重」。
4. **让他为他不同意的一方写最强论证** —— 本套的核心动作，也是最强的验收。
5. **给出你判断的地方要标明是判断** —— 别把你的立场混在事实叙述里。

**验收方式**：L5 能划界——能说出每一方在什么条件下是对的，以及需要什么新证据才会改变判断。

**该类型的专属翻车**：给一个「双方各有道理」的平衡结尾。事实分歧上是有对错的，和稀泥等于放弃教学。该说清的说清，只在价值层承认不可裁决。

## 四 · 教学法工具箱

上面八套是路径，这些是零件，可以按需嵌进任何一套。

| 方法 | 一句话做法 | 来源 | 证据 | 什么时候失效 |
|---|---|---|---|---|
| 费曼式讲解 | 让他不用术语讲给外行 | 以费曼命名的通俗方法（非其本人著述） | 经验共识 | 他不肯开口时无效；卡住时要给台阶不要干等 |
| 苏格拉底提问 | 用连续提问逼出他自己的矛盾 | 苏格拉底 | 经验共识 | 挫败感强，零基础慎用；他没有相关直觉时问不出东西 |
| 检索练习 | 盖住答案让他回忆 | Roediger & Karpicke 2006 | 强 | 完全没学过时无效，得先有输入 |
| 间隔重复 | 隔一段时间再取一次 | Ebbinghaus 1885 | 强 | **本技能不落盘，跨天无法执行**，只能会话内交错 |
| 交错练习 | 混着练不同类型 | Rohrer & Taylor 2007 | 强 | 初学单一技能时先集中，太早交错会过载 |
| 前置测验 | 学之前先考一遍 | Richland、Kornell 等 | 强 | 要明说「答不出正常」，否则打击信心 |
| 认知负荷控制 | 一次不超过 3–4 个新概念 | Sweller 1988 / Cowan 2001 | 强 | 已成块的旧知识不计入，别把熟悉内容也切碎 |
| 刻意练习 | 略超水平 + 明确目标 + 即时反馈 | Ericsson | 强 | **没有反馈渠道时退化成盲目重复**，此时改走别的方法 |
| 样例 + 撤脚手架 | 先看例题，逐步撤掉提示 | Sweller & Cooper 1985 | 强 | 对已有基础的人反而拖慢（专家逆转效应），会的人直接上手 |
| 双重编码 | 文字配图示 | Paivio | 强 | 图示和文字说的是两件事时反而增负 |
| 自我解释 | 让他讲每一步为什么 | Chi 等 | 强 | 他完全不会时问不出来，先给一个示范 |
| 合意困难 | 故意让学习过程别太顺 | Robert Bjork | 强 | 难到放弃就不合意了，要能撑住 |
| 概念转变 | 先暴露迷思 → 制造冲突 → 重构 | Posner 等 1982 | 强 | 需要他先说出自己的想法，他不说就没法暴露 |
| 记忆钩子 | 谐音 / 形状 / 词源 / 编故事 | 古典记忆术；关键词法 Atkinson | 强 | 钩子本身太复杂就成了新负担 |
| 先行组织者 | 开头先给一个总框架 | Ausubel | 强 | 框架太抽象时不如一个具体例子 |

**专家逆转效应值得单独记一笔**：对新手有效的方法（详细样例、逐步引导）对已有基础的人是负面的——他要跳步，你按住他讲基础会让他失去耐心且真的学得更慢。所以摸底不只是为了别讲浅了，也是为了别讲多了。

## 五 · 混合与冲突

**一个请求经常横跨两三类。** 处理原则：**主类型定整体流程，次类型切成独立段落插进去，不要混着教。**

例：「带我入门 Rust」主体是技能操作类（第 2 套），但所有权那一块是概念理论类（第 1 套，且必须配反例边界），标准库 API 是事实记忆类（第 3 套，且要在施工图里说清跨天记忆的取舍）。施工图的分段路径表里就该看出这种切换——每段标明它走哪一套。

**和用户偏好冲突时，用户赢，但要说明代价。** 他说「别让我做题，我就想听你讲」，那就讲，但在施工图的已知取舍里写明：「不做产出验收，我无法判断你哪里没通，你可能会带着虚高的自我评估离开。」他知情后的选择是他的权利，你的责任是别假装这样也能学会。

**时间预算不够时，砍知识树，不砍验收。** 少学两个知识点，剩下的真学会了，比八个都过一遍全是错觉强。验收是这套框架里唯一不能省的部分——它是你能看见学习者状态的唯一窗口。
