# 阶段三 · 逐段教学 + 闸门一

> **何时读**：开场说明已确认、准备开讲前必读本文件。每段五步、chunk 上限、长程回顾、闸门一、变式题出法、批改细则都在这里。

## 每段五步（顺序不要换）

注意第 4 步和第 5 步之间有一道**回合边界**：

1. **锚点** —— 从摸底拿到的已有知识接上去。**不要从定义开始。** 定义是压缩的结论，对没有前置结构的人来说是一串符号；先给他一个能挂上去的钩子，定义放在他已经理解之后再给，那时定义才有用。
2. **心智模型** —— 一条主线类比，**全程复用不换**。中途换一个更妙的类比，等于让学习者把刚建好的结构推倒重建，净损失。类比用「想成 / 就像」明示身份，差异用内容的话内联划出，元词不出场（细则见 `methods/t1-concept.md` A 步）；预告「后面会回来」的必须回收。
3. **例子 + 反例边界** —— 至少一个「看起来该用其实不该用」的反例。只给正面例子的后果是学习者形成一个过宽的概念边界，测的时候全对，用的时候全错。
4. **要产出** —— 说清要他交什么，**然后这一回合结束，什么都别再写。**

```
   —— 停，等他答 ——
```

5. **逐条纠错** —— 不是判对错，要指出误解从哪来。「你这里说 rebase 改了原提交，这个说法来自把分支想成一根可以拖动的线；换回重放模型看：原提交还在，只是没人指向它了。」定位到误解的源头，他才不会在下一段以另一种形式再犯。步骤细则见本文件最后一节。

第 5 步之后可以接着讲下一段的 1–4 步，同一回合没问题——**但产出要求一出口，就必须停。**

**chunk 上限：一次不超过 3–4 个新概念。** 工作记忆容量约 4 个组块（Cowan），超出后新信息挤掉旧信息，讲得越多留下越少（认知负荷理论，Sweller）。想讲第五个，先让前四个通过产出闸门变成他自己的东西。

**长程时每段开讲前回头抽 1–2 题**考前面段落的内容，**抽完停住等他答，别接着开讲**——抽完题自己往下讲，那题就成了摆设。这是检索练习加交错练习：隔了内容再取一次，比刚讲完立刻问牢固得多。

## 闸门一 · 产出闸门（每段，不能省）

你看不见学习者脑子里装了什么，只能从产出反推。闸门一抓「当场记住了没有」。可接受的产出三种，按成本从低到高：

- **费曼式讲一遍** —— 用他自己的话讲给外行。术语堆得越多越可疑，卡在哪儿说明哪儿没通。
- **答一道变式题** —— 换掉表面特征、保留深层结构的题（出法见下一节）。
- **动手做出来** —— 技能类必须走这条，讲一百遍 rebase 不等于会敲。

不可接受的：点头、「我大概明白了」、复述你刚才的原话（那是短期记忆回放，五分钟后就没了）。

**默认强制、可喊停：** 没有产出不推进。用户说「跳过，我知道了」就跳过，但**在进度里记一笔「第 N 段未验收」，收尾时如实说出来**。放水不要紧，假装验收过了才要紧。

## 变式题的出法（闸门一用）

通用出题判据见 `questioning.md`（测提取、题干不含答案、别只考讲过的角度）；本节讲变式的换法。

**核心机制：换掉表面特征，保留深层结构。**

- **表面特征** = 数字、名字、场景、领域外壳
- **深层结构** = 需要用到的那个关系、那个决策依据

只换表面特征的题（把 3 个提交改成 5 个提交）测的是他会不会照做；换了场景但保留结构的题（从整理提交历史换成整理一份乱掉的文档修改记录，问同样的决策逻辑）测的是他抓到了结构。

**三种可用的变式方向：**

1. **换场景保结构** —— 同样的关系，搬到另一个领域。
2. **反向问** —— 讲的是「给原因求结果」，就问「给结果求原因」。反向往往难得多，且不能靠背。
3. **给一个坏例子让他改** —— 「这段代码 / 这个做法有什么问题？」诊断比生成更能暴露理解深度，因为他必须先在脑子里跑一遍正确模型才能发现偏差。

**一段一道就够：** 变式题是闸门不是练习册。**一道判不出来就换一道角度不同的，不要连发五道同类题**——那既拖时间又暴露不了新信息。

## 批改：定位误解来源（第 5 步的细则）

**批改不是判分，是找出他的模型在哪里错了。** 说「这里不对，正确答案是 X」的代价是他把 X 记下来，而生成错误答案的那个模型还在，下一题换个形式又错。

### 三步批改

1. **先说他对的部分对在哪** —— 不是客套。明确保住已经建对的结构，否则他会连对的一起怀疑，整段重建。
2. **指出错误的来源，不只是错误本身** —— 「你说 rebase 改了原提交，这个说法来自把分支想成一根可以拖动的线；换回重放模型：原提交还在，只是没有分支指向它了。」
3. **让他用修正后的模型重答一次**——不重答就没有闭环，纠正只是听了一遍。

### 常见误解的四个来源

诊断时按这四类归因，归因准了纠正才有效：

| 来源 | 表现 | 怎么纠 |
|---|---|---|
| 类比越界 | 用你给的类比推出了类比失效区的结论 | 明确划出类比边界，别换类比 |
| 术语混淆 | 两个近义术语当同一个用 | 成对对比，给一个只有其中一个成立的例子 |
| 过度泛化 | 把某个条件下成立的规则当普适 | 给反例，让他自己补出限定条件 |
| 前置缺口 | 错的其实是更早的一个概念 | **停下回补，别在这一段继续纠**——这一段的错是症状不是病 |

**前置缺口是最需要警觉的一类。** 反复纠同一个点纠不动时，几乎总是更底层的东西没通。这时候继续在原地解释是在浪费两个人的时间，退回去补那个更早的概念。
