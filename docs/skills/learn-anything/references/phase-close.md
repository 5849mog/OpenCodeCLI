# 阶段末 · 闸门二（迁移闸门）+ 状态文件与已知取舍 + 收尾

> **何时读**：单元完成收尾、或长程每次会话收尾前必读本文件。门二、迁移题细则、考官模板、长程状态文件、收尾要说的话都在这里。

## 闸门二 · 迁移闸门（收尾）· 派独立考官

你看不见学习者脑子里装了什么，只能从产出反推。门二抓「换个场景还会不会用」——这才是门一之外必须单独验的一关。用 `Agent` 派一个子代理当考官，三条硬要求：

1. **只给它 `能力目标 + 掌握层级 + 学习者的产出原文`，不要给它你的讲解稿。** 教的人出题会不自觉地只考自己讲过的角度、用自己用过的措辞，那是自我确认，测出来的是「他记住了我说的话」而不是「他会用这个知识」。考官不知道你怎么讲的，才出得出真正的新情境题。
2. **让它出三类题**：新情境应用 / 边界与反例 / **让学习者自己出一道考别人的题**。第三类最灵：能出题说明他抓到了结构（知道哪里容易错），只会答题说明他只抓到了结论。
3. **判 fail 时要它指明是哪一段的哪个卡点没过**，回那一段补，补完让**同一个考官**复核（它有上一轮上下文，复核更准）。

**考官出完题，你把题发给用户，然后这一回合结束。** 考官只负责出题和定评分要点，答题的是用户——题发出去不停住，等于自问自答。对用户就说「最后几道题，换个场景看看你会不会用」，**不要提「独立考官」「迁移闸门」这些词**，那是你的内部机制，他只需要知道要答几道题。

不要自己出题代替考官——你会系统性漏掉自己没讲的角度，而那正是要测的地方。也不要在派考官之前先自己考一轮，那是重复评审，白烧一次往返。**这条禁令的前提是你有 `Agent` 工具；没有的话，由下面「降级路径」取代它。**

**两者不可替代**：门一干净只证明「当场记住了」，不证明「换个场景还会用」；而门二发现的问题往往在某个具体的段落里，只有门一的逐段记录能告诉你回哪一段补。

**何时可以省门二**：速览型请求（见核心文件「速览细则」，默认省）；用途答「满足好奇」或目标层级 ≤ L3；或用户明说「我就想大概了解一下」。省了要说出来，别默默省掉让他以为过了考核。

**没有 `Agent` 工具时怎么办**（子代理环境里会遇到）：门二不能因此消失，但要降级并说明。降级做法是**先只看能力目标和他的产出原文把三道题写完，写完之前不回看自己的讲解稿**——用流程隔离模拟考官的独立性，效果弱一些但方向对。写完自查两句：「有几道用了我讲解时的例子或措辞」——命中的换掉；「考的角度有没有至少一道我压根没讲过」——一道都没有就重出（角度泄漏是自己出题的主要失效方式，措辞只是症状）。然后用人话告诉他折扣，**不提「考官」这个内部件**：「这几道题是我自己出、自己判的，没第二个人把关，可能判宽了。要更保险，过几天自己再做一遍。」这比假装过关好，也比省掉好。

## 迁移题细则（出题与考官的共同依据）

通用出题判据见 `questioning.md`；本节讲迁移距离与门二的三类题。

### 迁移距离要分两档

- **近迁移** —— 同领域新情境。例：教了用 rebase 压提交，问怎么用它改一个历史提交的作者信息。
- **远迁移** —— 跨领域但结构相同。例：教了熵，问为什么打乱的房间不会自己整理好，而整理好的房间会自己乱。

远迁移是真正的掌握标志，但**别拿远迁移一票否决**——远迁移失败很常见，且不代表近迁移能力不行。施工图里的目标层级到 L4 就用近迁移判，到 L5–L6 才加远迁移。

### 必出的三类题

1. **新情境应用** —— 他没见过的情境，需要主动选出该用哪个知识点。**「该用哪个」这个判断本身就是要测的东西**，所以题干里不要暗示。
2. **边界与反例** —— 「什么时候这个做法会失效 / 反过来更好？」这道题几乎无法靠记忆通过。
3. **让他自己出一道题** —— 要求：出一道能考出别人是否真懂这个知识点的题，并说明这道题为什么能考出来。

第三类最灵，值得解释一下为什么：**出题需要知道哪里容易错，而知道哪里容易错说明他有了这个知识的结构图。** 只会答题的人出不出好题——他会出一道抄课本定义的题，那个反应本身就是诊断结果。

## 考官 prompt 模板（发给 Agent 用）

```
你是独立考官。你的任务是判断一个学习者是否真的掌握了某个知识，
并给出可执行的判定。你没有看过教学过程，这是刻意的——请完全基于
下面的目标和学习者的原始产出来出题和判定。

【能力目标】
（照抄施工图里的一句能力目标）

【目标掌握层级】
（例：L5 能划界。附上该级的判定标准：说出失效条件和反例，且反例成立）

【学习者的产出原文】
（逐段贴他自己写的东西 / 讲解 / 答案，保留原始措辞，不要润色，
  不要加你的评价。措辞里的破绽是重要信息。）

【已知未验收的段落】
（如实列出他喊停跳过的段落，例：第 3 段未验收）

请做三件事：

1. 出三道题，分别是：
   - 新情境应用题（他没见过的情境，且题干不要暗示该用哪个知识点）
   - 边界与反例题（什么时候这个知识不适用 / 反过来更好）
   - 元题：要求学习者自己出一道能考出别人是否真懂的题，并说明为什么这道题能考出来

2. 对每道题写出你的评分要点：什么样的回答算过，什么样的回答是
   「看起来对但实际没懂」，后者要具体描述它长什么样。

3. 基于他现有的产出原文，先给一个预判：你认为他大概会在哪道题上
   卡住，为什么。这个预判用于定位补课的位置。

输出格式：三道题 + 每道题的评分要点 + 预判。不要给学习者建议，
不要安慰性评语，判定要能直接执行。
```

### 复核时怎么派

学习者答完、补完之后，**用 `SendMessage` 发给同一个考官**，不要新派一个。它有上一轮的上下文（包括它自己的预判），复核判得更准，也能看出这次是真的通了还是换了个说法。

复核时给它：他的答案原文 + 你针对失败点补讲后他的重答。让它给最终 verdict，并明确说出「哪一级达标了、哪一级没达标」。

**没有 `Agent` / `SendMessage` 工具时**：复核由你自己做，但先把「上一轮的三道题 + 他答错的具体位置 + 你补讲了什么」写成清单，再对着清单判。不要边看他的重答边回忆上一轮——他会说得更顺，而顺畅和正确是两件事。判完同样声明「这一关的复核也是我自己做的，可靠性打折」。

## 状态文件与已知取舍（不藏）

**落盘边界是用户定的**：速览和单元一次会话学完，**什么都不写**；只有长程写状态文件——因为长程必然跨会话，不落盘历史就断。

**状态文件**：`~/.learn-anything/sessions/<主题slug>.md`，施工图定稿时建档（见 `phase-plan.md`），**每次会话收尾更新**。五块内容：

1. 内部施工图全文——长程的施工图就住在这里，可核查
2. 进度——走到第几段、下次从哪继续
3. 门一逐段记录——哪几段过了、哪几段是他喊停跳过的
4. 他每段产出的原话摘录——保留他自己的措辞，不要润色。门二要拿这个当输入（见门二第 1 条），润色过就失去诊断价值，他措辞里的破绽正是考官要看的东西
5. 下次回顾题 2–3 道

读到本次会话新读了哪个 references 文件，就在文件末尾的「已读」清单里记一笔——装载纪律变成自记录。

**首次建档时就告诉他**：文件在哪、下次新开对话说「继续学 X」我直接读文件接上，不用他贴任何东西。

**跨对话续学（长程）**：新对话听到「继续学 X」→ 在 `~/.learn-anything/sessions/` 按主题找文件 → 读取 → 用文件里的回顾题开场（检索即复习）→ 接断点走。**不要重走全套**：不重新摸底、不重出开场说明，先读文件再说话。找不到文件或对不上主题，问一句，别猜。

**即使有状态文件，跨天的间隔重复仍不能自动发生**——文件不会提醒任何人回来学，主动回来仍靠他。间隔效应的抗衡手段是分布在多天的重取（Ebbinghaus），你能做的只是每次续学开场用文件里的回顾题做检索练习，强度低于真正的间隔重复。别让他以为存了文件就等于记住了；记忆类知识这条要额外说明（见 `methods/t3-memory.md`）。

**单元的收尾产出仍在对话里**：带走清单（自测题 + 答案 + 他的高频误解 3 条 + 下次自查建议）直接输出，他想存自己复制。只在单元完成、长程整程走完时给；速览两句话结束。

## 收尾时说什么

**分三种情况，别一律套五件事：**

- **速览** —— 按核心文件「速览细则」：两句话收尾，不附自测题。
- **长程的每次会话** —— 迷你收尾：这次会了什么、下次从哪继续、三道带走的题；**更新状态文件**（五块内容见上节）。门二分两层：**每次会话末自己出一道跨段迁移题**（轻量，只考本次会话与上一段的连接处），整程末尾再派考官跑完整门二——只在整程末尾考一次的风险是中间几周的误解全程不暴露，正好撞上「讲完统一考」（`pitfalls.md` 第 12 条）。每次会话的门一记录要进状态文件，门二判 fail 时靠它定位回哪一段。
- **单元完成 / 长程走完** —— 走下面完整的五件事。

说清这五件事，别只说「今天就学到这里」：

1. **你现在会什么** —— 对着能力目标逐条说，到了哪一级。用他的产出当证据：「第 2 段你独立压完了提交，这是 L4。」
2. **你还不会什么** —— 明确说砍掉的部分和没过闸的段落。这一条不许含糊，含糊的代价是他带着虚高的自我评估去用，然后在真实场景里翻车，还不知道为什么。
3. **你的高频误解** —— 从纠错记录里提 2–3 条，指出它们的共同来源。同一个错误换三个形式出现，说明底层有一个错的模型，指出来比改三次现象有用。
4. **带走清单** —— 自测题 + 答案 + 下次自查建议（见上节）。
5. **自检，但别把自检说出口** —— 对照 `references/pitfalls.md` 的清单核一遍：有没有哪一段其实是在罗列而不是在教、有没有哪次验收其实是假验收。**这一步的结果默认不告诉用户**——「已对照反 AI 教学清单，无违例」是报菜名，而且他根本不关心你的质检流程。只有一种情况要说出来：自检真的发现了会影响他的问题（比如某段你其实没验收就过了），那就用人话讲那个问题本身，不提清单：「第 3 段我没真正确认过你会了，那块你自己再试一次比较稳。」

如果这次有为了时间预算做的取舍（比如某个原理只给了结论没给推导），主动说明，不要藏。
