# 教学法工具箱

> **何时读**：任何类型的教学都可能用到其中的零件，和对应的 t 系列文件（t1–t8 中按 route.md 路由的那一份）一起读。

上面八套是路径，这些是零件，可以按需嵌进任何一套。

| 方法 | 一句话做法 | 来源 | 证据 | 什么时候失效 |
|---|---|---|---|---|
| 费曼式讲解 | 让他不用术语讲给外行 | 以费曼命名的通俗方法（非其本人著述） | 【经验共识】 | 他不肯开口时无效；卡住时要给台阶不要干等 |
| 苏格拉底提问 | 用连续提问逼出他自己的矛盾 | 苏格拉底 | 【经验共识】 | 挫败感强，零基础慎用；他没有相关直觉时问不出东西 |
| 检索练习 | 盖住答案让他回忆 | Roediger & Karpicke 2006 | 【实验证据强】 | 完全没学过时无效，得先有输入 |
| 间隔重复 | 隔一段时间再取一次 | Ebbinghaus 1885 | 【实验证据强】 | 跨天执行靠用户主动回来（状态文件不会提醒他），会话内只能交错 |
| 交错练习 | 混着练不同类型 | Rohrer & Taylor 2007 | 【实验证据强】 | 初学单一技能时先集中，太早交错会过载 |
| 前置测验 | 学之前先考一遍 | Richland、Kornell 等 | 【实验证据强】 | 要明说「答不出正常」，否则打击信心 |
| 认知负荷控制 | 一次不超过 3–4 个新概念 | Sweller 1988 / Cowan 2001 | 【实验证据强】 | 已成块的旧知识不计入，别把熟悉内容也切碎 |
| 刻意练习 | 略超水平 + 明确目标 + 即时反馈 | Ericsson | 【实验证据强】 | **没有反馈渠道时退化成盲目重复**，此时改走别的方法 |
| 样例 + 撤脚手架 | 先看例题，逐步撤掉提示 | Sweller & Cooper 1985 | 【实验证据强】 | 对已有基础的人反而拖慢（专家逆转效应），会的人直接上手 |
| 双重编码 | 文字配图示 | Paivio | 【实验证据强】 | 图示和文字说的是两件事时反而增负 |
| 自我解释 | 让他讲每一步为什么 | Chi 等 | 【实验证据强】 | 他完全不会时问不出来，先给一个示范 |
| 合意困难 | 故意让学习过程别太顺 | Robert Bjork | 【实验证据强】 | 难到放弃就不合意了，要能撑住 |
| 概念转变 | 先暴露迷思 → 制造冲突 → 重构 | Posner 等 1982 | 【实验证据强】 | 需要他先说出自己的想法，他不说就没法暴露 |
| 记忆钩子 | 谐音 / 形状 / 词源 / 编故事 | 古典记忆术；关键词法 Atkinson | 【实验证据强】 | 钩子本身太复杂就成了新负担 |
| 先行组织者 | 开头先给一个总框架 | Ausubel | 【实验证据强】 | 框架太抽象时不如一个具体例子 |

**专家逆转效应值得单独记一笔**：对新手有效的方法（详细样例、逐步引导）对已有基础的人是负面的——他要跳步，你按住他讲基础会让他失去耐心且真的学得更慢。所以摸底不只是为了别讲浅了，也是为了别讲多了。
