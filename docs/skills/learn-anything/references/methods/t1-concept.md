# 第 1 套 · 概念理论类 —— ADEPT + 主线类比 + 反例边界

> **何时读**：route.md 判定本知识属概念理论类时读。单元走下面全部六步；速览只取其中两条——类比立起与划界、反例边界。

**承诺**：让他能把这个概念用自己的话讲给外行，并且知道它管到哪儿为止。

**适用**：熵、通胀、attention、期权 Greeks、递归、免疫应答——凡是「一个东西是什么、为什么这样」。

**忌用**：需要肌肉记忆的操作，和大量并列的事实。

**来源**：ADEPT 框架（Kalid Azad，BetterExplained）【经验共识】；类比迁移的结构映射理论（Dedre Gentner）【实验证据强】；概念转变模型（Posner 等，1982；物理教育研究里的迷思概念工作）【实验证据强】。

**流程**：

1. **A 类比（Analogy）** —— 先给一个他已经熟悉的东西，用「把 X 想成 Y」「X 就像 Y」**明示这是类比**——别用「X 就是 Y」的断言开局，那会让他把比方当事实，等你谈边界时他已经懵了。这一步是全套的地基：新概念必须挂在旧结构上，否则只能死记。紧接着用内容的话讲清它和真东西差在哪，例：「把 attention 想成在一堆文件里打分挑重点——但它不是真的『挑一个』，是按分数加权全都取一点。」**全程不对用户说「类比」「失效」这类元词**——这是你执行的动作，不是你说出的话。差异句跟着类比走，不必堆在开头；后面内容用到这条差异时再展开。预告「后面会回来」的必须回收，没打算展开的别预告。
2. **D 图示（Diagram）** —— 画出来或用文字描述空间关系。语言和视觉走两条编码通道，双通道记得牢（双重编码，Allan Paivio）【实验证据强】。纯文字对话里就用结构化的文字图示，别省。
3. **E 例子（Example）** —— 一个具体到有数字的例子，走一遍。
4. **P 大白话（Plain English）** —— 不带任何术语讲一遍。这一步是给你自己的检查：讲不出大白话说明你也没通。
5. **T 技术定义（Technical definition）** —— **最后才给定义**。定义是压缩过的结论，放最前面等于让他背一串符号。放最后，定义就变成了「原来那句话就是这个意思」的确认。
6. **反例边界** —— 至少一个「看起来该用其实不该用」的例子。

**验收方式**：L2 用自己的话讲一遍 → L3 举一个你没给过的新例子 → L5 说出边界。**举新例子这一步不能省**，它是概念类唯一能区分「理解了结构」和「记住了你的例子」的测法。速览只走到 L3，边界讲了不验。

**该类型的专属翻车**：中途换类比。第二个类比再妙也别换——学习者刚在第一个类比上建好结构，换一个等于推倒重建，净损失。要补充就在原类比上加细节。
