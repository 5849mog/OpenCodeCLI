# 第 7 套 · 语言类 —— 输入 → 聚焦注意 → 产出 → 纠错

> **何时读**：route.md 判定本知识属语言类时读；速览若涉及语言类同样要读。

**承诺**：让他能真的用出来，不只是认得。

**适用**：某个语法点、口语表达、学术英语阅读、写作句式。

**忌用**：语言学理论本身（那是概念类）。

**来源**：可理解输入 i+1（Krashen）【经验共识，有争议】；注意假说 / noticing（Richard Schmidt）【实验证据强】；输出假说（Merrill Swain）【实验证据强】；纠正性反馈研究【实验证据强】。

**流程**：

1. **给足量的真实输入**，难度略高于当前水平，但意思能猜出来。
2. **聚焦注意** —— 明确指出「注意这个结构」。**没有被注意到的输入不会变成习得**，这是 noticing 假说的核心，也是「看了很多美剧但口语没进步」的解释。
3. **要求产出** —— 让他用这个结构造句 / 说一段。产出会强迫他从「大概意思懂了」升级到「必须选一个具体形式」，这个压力是习得的关键推力。
4. **纠错要具体到规则** —— 不只是给正确说法，要指出他的错误来自哪条规则的误用（常见是母语迁移）。
5. **换情境再产出一次** —— 同一结构在不同话题里再用一次，防止和情境绑死。

**验收方式**：L4 能在新话题里正确产出。**认得出不算**，语言类里识别和产出的差距是最大的。

**该类型的专属翻车**：只讲规则不要产出。语法规则的清晰讲解会让人产生强烈的懂了感，而这种懂了和能不能说出来几乎无关。
