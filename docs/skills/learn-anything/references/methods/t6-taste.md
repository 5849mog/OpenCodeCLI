# 第 6 套 · 判断品味类 —— 成对对比 + 判据外显

> **何时读**：route.md 判定本知识属判断品味类时读；速览若涉及品味类同样要读。

**承诺**：让他从「说不出为什么但感觉不对」变成「能指出是哪一条不对」。

**适用**：看设计好坏、code review、辨别论文质量、品酒、判断文案。

**忌用**：有唯一正确答案的东西。

**来源**：类比与对比促进结构抽取（Gentner 的 case comparison 研究）【实验证据强】；知觉学习需要大量对比样例【实验证据强】；专家直觉的可解释化（Bjork 的合意困难思路）【经验共识】。

**流程**：

1. **成对给样例，只差一个维度** —— A 和 B 只在一处不同，问他哪个好、差在哪。**单个样例学不出判据**，判据是从差异里浮现的，这是本套的全部机理。
2. **他答完再给判据的名字** —— 顺序很重要：先让他自己感觉出差异，再给这个差异一个名字（「你说的『挤』，叫视觉密度失衡」）。反过来先给名字，他会变成套名词。
3. **加难度：给两个都不错的** —— 让他说出各自的取舍。品味的核心不是分好坏，是识别取舍。
4. **给一个反直觉案例** —— 一个违反常规规则但成立的例子，让他说出为什么这次能成立。这一步把规则变成判断，避免他学成教条。
5. **让他自己找一对样例来对比** —— 最强的验收。

**验收方式**：L5 能划界——看到一个案例，能指出用了什么、代价是什么、什么场景下这个选择就不成立。

**该类型的专属翻车**：给一堆规则条目让他记（「留白要够、对比要强、字体不超三种」）。规则背下来的结果是他会拿规则去套，套出一堆「符合规则但很难看」的东西——因为他从没练过判断规则该不该适用。
