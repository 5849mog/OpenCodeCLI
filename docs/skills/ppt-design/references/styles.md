# 风格库

所有字号假定画布 **13.33 × 7.5 英寸**（`LAYOUT_WIDE`）。若改用 10 英寸宽画布，所有字号和页边距乘 0.75。

所有字体都限定在 **qa.py 的跨平台安全名单**（`scripts/qa.py` 的 `_SAFE_FONTS`，含 macOS 与日韩常见系统字体）且 Windows / Office 自带，避免在用户机器上被静默替换。

## 一 · 风格的来源（硬规则，先于一切）

**没有可指认来源的风格，不许入库。** 这是本库存在的理由：AI 审美来源于 AI 生成语料，而语料已被 AI 生成物喂大——凭"科技感""高级感"这类印象即兴配出来的"风格"，大概率就是 AI 晒干的样子（本库当年的「科技深空」就是这么生出来的，已成反面教材）。

- **来源要素**：真实世界的设计运动、印刷品、工艺，加上年代与人物/实物。例：「Müller-Brockmann 1958 网格系统」「Herschel 蓝晒 1842」「理想科学 孔版印刷」。
- **效果承诺**：每个预设必须说清这一套"承诺给你什么"——舒服／眼前一亮／专业可信。说不出承诺的风格，要么删，要么回去找来源和承诺。
- **新风格流程**：用户点名库里没有的风格时，先找来源、定承诺，再定色值字体；**禁止跳过来源直接调色**。
- 年代与出处宁可用「约」「此前」这类留有余地的措辞，也不要编造看似精确的年份与人物——一条编造的「来源」比没有来源更糟，它会让整条风格纪律失去信用。

## 1.1 色值是参考，用色纪律才是风格

每个预设给出的 hex 是**参考调色**，不是铁律。真正定义风格的是**用色纪律**——几个角色、各占多少、点缀色只准出现在哪里。原因有两层：

1. **写死的坏配色会永久污染库。** 本库当年那套「深蓝底 + 霓虹青」就是凭"科技感"印象配出来的，一旦写进预设，每份用它的 deck 都继承同一份坏品味。纪律不会有这个问题。
2. **同一风格的每份 deck 配色都一样，用多了就腻。** 纪律允许按主题重推色值，同时保证风格不散。

所以每个预设下面都有一节「用色纪律」。**执行时纪律必须遵守，色值可以替换。** 标注 ✅ 的预设色值已经渲染验证过，直接用最省事。

### 按主题重推色值的方法

1. 从主题的**真实物料**取色：产地、工艺、品牌、实物、材质。不要从"感觉"取色。
2. **保持原预设的角色数与占比不变**——这是纪律，换的只是具体色值。
3. 判据沿用第一节那条：把这套配色挪到一个完全无关的主题上会不出戏，才算够具体。
4. 重推后在规格书的「配色」一行注明「本次推导值」，并写清取色依据。

## 二 · 反 AI 审美清单（禁止默认）

判断标准：这些特征出现在 AI 生成语料里的频率远高于人类设计。单次出现可能合法，**作为默认值批量出现就是 AI 脸**。

### 皮肤层（配色/质感）

| 特征 | 识别方式 |
|---|---|
| 深蓝底 + 霓虹青 | `#0B1220` 类深蓝 + `#22D3EE``#00E0FF` 类青做强调、发光、描边 |
| 黑金豪华 | 近黑底 + 金色/铜色渐变或描边，"奢"味 |
| 紫粉渐变 | 蓝紫→品红渐变、渐变标题 |
| 玻璃拟态磨砂 | 半透明磨砂层、光晕、低对比 |
| 蓝白 + 蓝色渐变 | `#1F4E79`→`#2E75B6` 类纵向渐变块，配白底 |
| 圆润 3D 吉祥物 | 卡通拟人球体/软糖质感 icon |
| emoji 图标堆 | 正文里用 🚀📊✅ 类符号当图标 |
| 正文里塞几何/数学符号 | 用 `△ □ ○ ∠ ⊥ ∥` 当排版元素——中文字体里它们只有汉字四成大小、笔画细一档，一眼 LLM 文本味。句子里写汉字（三角形/角），数学式走 `inject_math`，图形用 `inject_figure`（pitfalls #29；`①`、`½` 不属此列，它们是满尺寸的） |
| 图标家族混用 | 线性/填充混用、粗细不一、几个素材库的图标拼盘 |
| 图标 + 圆角卡片 + 投影三件套 | 每个要点一张圆角卡片配图标加投影——企业素材风的固定配方 |
| 素材网站默认风格照片直贴 | 未做任何处理的高饱和 / 蓝紫渐变图库照，与 deck 风格无关 |
| 无理由的米白纸感 | 主题与纸无关却用 `#F5F5DC``#FAF0E6` 类底色 |
| 默认蓝大按钮 | 主题无关的蓝紫 CTA 块 |

### 结构层（版式）

| 特征 | 识别方式 |
|---|---|
| **视觉焦点缺失或平均分配** | 翻开一页，1 秒内说不清眼睛落在哪；或重点元素全用同一强调色、无主次——本次「科技深空」的病理 |
| 每页同一版面骨架 | 连续 ≥4 页页眉/页脚/编号完全相同 |
| 全宽页脚色带 / 进度条 | 每页底部的装饰横带、分段进度块 |
| 卡片方阵滥用 | ≥3 张并排卡重复出现，连续两页即过量 |
| 图标当装饰铺满 | 每条要点都配图标、整页图标 >3 个，图标失去路标作用（纪律：每页 ≤3、单一颜色角色） |
| 罐头示意图 | 用现成的箭头流程/循环/金字塔骨架套任何内容，图形与要表达的判断没有专属关系（示意图必须从主张长出来，不是先有骨架再填字） |
| 纯文字 + 圆角矩形堆叠 | 整页无图片、无图表、无连接线 |
| 通用三件套封面 | 眉标 + 标题 + 副标题 + 关键词，像任何主题都能用 |
| 标题下装饰下划线 / 侧边色条 | 老牌 AI 脸特征，见上一版「反模板清单」的完整版 |

**Bento 网格（不等权分块）单独说明**：它本身是被 AI 用得非常高频的通用布局，但作为**真实存在**的版式结构可以经用户点名使用——只是不许默认。只有用户主动指定，或主题确实适配时再用。

**考卷/教科书式插图是例外**：函数图像、带 A/B/C 顶点的几何图、坐标网格，这些的参照标准就是印刷出来的课本与卷子——「像教科书」是**目标**，不算 AI 味，也不适用上面「罐头示意图」那条（那条针对的是拿通用流程骨架套内容）。但要守住两点：图必须由 `scripts/inject_figure.py` 的声明式规格按**具体坐标/表达式**生成（不许有"自动生成一个三角形"这种罐头入口），且几何关系要写进「约束」验算、图要能对得上题面。

## 四 · 十二套预设

### 1. 日式和风 Japanese Wabi ✅

**承诺**：舒服。排版松弛、对比克制、读起来不累——安静中有底气。
**适用**：文化、展览、茶饮食品、设计类主题；需要呼吸感的内容。
**忌用**：数据密集的汇报；需要强推销感的场合。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `13110F` | 漆器黑，占 65% |
| CARD | `221E1A` | 格子底（比背景微亮一档） |
| HERO | `2C2724` | 主格底（再亮一档，标记层级） |
| TILE | `3A332D` | 示意图小块 |
| TEXT | `F1EBE0` | 米白 |
| MUTED | `9C9287` | 次级文字（在 CARD 上约 6.2:1，安全） |
| ACCENT | `D9452C` | 朱红，唯一强调色，占比约 3% |

**字体**：`宋体`（标题，Windows 唯一自带的明朝体系衬线）+ `微软雅黑`（正文）
**字号**：主标 44 / 主格标题 21 / 格标题 17 / 正文 14.5 / 小字 12.5 / 脚注 12
**母题**：大小不等的圆角格子（圆角 0.14 英寸）铺满，**靠底色明度微差分格，不画描边、不加色条**；"安静"来自大面积留白与低噪声排版。

**用色纪律**（必守，色值可换）
- 角色数 5：底 + 两档格子底 + 文字 + 次级文字，加**唯一**一个点缀。不许第六个色相。
- 三档格子底必须是**同一色相的明度微差**（每档间隔约 6–10 点明度），不许换色相分区。
- 底色占 60–70%；点缀 ≤3%。
- 点缀（朱红）**只准**出现在一处：全页最重要那一格的主体块。不许给编号、描边、小方块、正文。
- 靠明度分格是这套风格的立身之本 —— 一旦改用描边或色条，它就不是和风了。

```js
const BG="13110F", CARD="221E1A", HERO="2C2724", TILE="3A332D",
      TEXT="F1EBE0", MUTED="9C9287", ACCENT="D9452C";
const SERIF="宋体", SANS="微软雅黑";
```

### 2. 新粗野主义 Neo-Brutalism ✅

**承诺**：眼前一亮。黑框硬影、撞色、刻意歪斜——第一秒撞进眼睛，哪怕冒犯。
**适用**：创意提案、独立产品、年轻品牌。
**忌用**：金融、医疗、政府、法务，以及客户要"可靠"而不是"有个性"的场合。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `FFD52E` | 亮黄场，占 65% |
| INK | `111111` | 纯黑：描边、正文、硬阴影 |
| PAPER | `FFFFFF` | 卡片底 |
| PINK | `FF4E8E` | 强调一 |
| BLUE | `2E5BFF` | 强调二 |

**字体**：`Arial Black`（拉丁与编号）+ `微软雅黑 Bold`（中文）
**字号**：主标 62 / 编号 40 / 卡标 19 / 小标 16 / 正文 14 / 脚注 12
**母题**：3pt 纯黑描边 + **零模糊纯色硬阴影**统一向右下偏 7pt + 一处刻意旋转（约 7 度）
**BANNED**：任何柔和阴影（是本风格唯一不可妥协项，pptxgenjs 会用 `blur||8` 吞掉 `blur:0`，见 pitfalls #2）、圆角、渐变、旋转超过 1 处。

**用色纪律**（必守，色值可换）
- 角色数 5：亮场底 + 纯黑 + 卡片白 + **两个**高饱和撞色。不许第六个。
- 底色占 60–70%；纯黑承载全部描边、正文与阴影；两个撞色各出现 2–3 次，形成呼应而不是散点。
- 撞色可以整组替换（黄底换成亮绿/亮橙都成立），但必须保持"一个高饱和亮场 + 纯黑结构 + 两个撞色"的关系。
- 黑块配**撞色**阴影（而不是黑色阴影）是地道手法，全页用一次就够。
- 描边一律纯黑同一宽度，不许分粗细档 —— 它的"乱"建立在绝对统一的描边与对齐上。

```js
const BG="FFD52E", INK="111111", PAPER="FFFFFF", PINK="FF4E8E", BLUE="2E5BFF";
const DISP="Arial Black", SANS="微软雅黑";
const hard=(c=INK,o=7)=>({type:"outer",color:c,blur:0.0001,offset:o,angle:45,opacity:1.0});
const edge=()=>({color:INK,width:3});
```

### 3. 蓝图纸工程风 Blueprint

**承诺**：眼前一亮——技术主题的意外感。图纸时代的信息质感，看着像从工程局里拿出来的。
**SOURCE**：Herschel 蓝晒工艺（约 1842，蓝底白像）与 20 世纪工程蓝图传统（约 1917 起的 Diazotype 复印蓝图：蓝纸白线、图框、标题栏、工程字体、戳记）。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `1D4E89` | 蓝图蓝，占 70% |
| PANEL | `163A63` | 次级面（标题栏、批注区，比底深一档） |
| LINE | `DCE7EF` | 白线：网格、图框、正文 |
| TEXT | `F4F8FA` | 主文字 |
| MUTED | `A7C6D8` | 次级文字 |
| STAMP | `C13B2E` | 印泥红：戳记/印章，全页唯一强调 |

**字体**：`黑体`（标题，工程字样感）+ `微软雅黑`（正文）+ `Arial`（拉丁/编号）
**字号**：主标 56 / 栏标 18 / 正文 15 / 图注与批注 12
**母题**：**真实的工程图框**——双线外框 + 右下角标题栏（内含"项目/图号/比例/日期/绘图"字段），1px 白线网格 + 十字定位马克 + 一枚印泥红戳。
**BANNED**：霓虹青、任何发光/渐变、圆角卡片、徽章/标签、"科技未来感"。它要的是"过去的工程"，不是"未来机房"。

**用色纪律**（必守，色值可换）
- 角色数 3 个色相：**一个底色 + 一个线色 + 一个点缀**。不许第四个色相（次级面只能是底色压暗的同色相）。
- 底色占 65–75%；**一个线色承载全部结构**——图框、网格、连接线、正文、标签，一律同色。
- 点缀（印泥红）≤2%，**只准**用在戳记与"当前状态/关键路径"两类元素上。**不许**给编号、格子描边、小方块、正文 —— 这条正是本库当年「深蓝科技」翻车的直接病因（点缀洒满全场 = 没有重点）。
- **戳记不许把红字直接压在深蓝底上**：#C13B2E 压 #1D4E89 对比度约 1.6:1，qa 判硬伤、投屏也看不清。真实蓝图里的戳是盖在浅色纸签上的——给戳记一个 LINE 色的浅底托板（白底红字）；公式、图表一类图片型强调元素同理：深底上要么用 LINE 亮色，要么加浅底托板。**强调色要压深底，就得有托板**。
- 底色换蓝图蓝以外的颜色也成立（工程绿、晒图棕），但"深底 + 单一线色 + 一个红戳"的关系不能动。

```js
const BG="1D4E89", PANEL="163A63", LINE="DCE7EF", TEXT="F4F8FA",
      MUTED="A7C6D8", STAMP="C13B2E";
const HEI="黑体", SANS="微软雅黑", LATIN="Arial";
```

### 4. 黑色电影海报 Film Noir

**承诺**：眼前一亮——戏剧性。黑白片的明暗对比，像一张 1940 年代电影海报。
**SOURCE**：1940–50 年代黑色电影（Film Noir）纸质海报排印：墨黑、强对比、硬边光带、奶油黄/红文字。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `0E0D0C` | 墨黑，占 70% |
| PANEL | `1C1A17` | 次级面（比底微亮） |
| TEXT | `F5EDDC` | 奶油白 |
| MUTED | `A79C86` | 次级文字 |
| ACCENT | `E3B341` | 海报黄：唯一强调，用于一个焦点词或光带 |

**字体**：`宋体`（标题，给一点点老排印的衬线风）+ `微软雅黑`（正文）+ `Georgia`（拉丁）
**字号**：主标 64 / 副标 26 / 正文 15 / 脚注 12
**母题**：**硬边对角光带**（一条 3–6 度倾斜的色带切过版面——模拟百叶窗光影），配大号紧凑标题；阴影全部零模糊。
**BANNED**：金色/铜色渐变（"奢"=AI 高频，这里必须忍住用海报黄）、圆角、柔光、双强调色。

**用色纪律**（必守，色值可换）
- 角色数 3 个色相：墨黑底 + 奶油白字 + **一个**海报黄。次级面只能是底色提亮的同色相。
- 底色占 65–75%；点缀 ≤5%，只准给一个焦点词或一条光带。
- **点缀绝不能偏向金铜**：一旦带金属感就落进「黑金豪华」这条 AI 高频里。海报黄、砖红、锈橙都行，金色不行。
- 光带是结构不是装饰：它必须切在净空区，且承担分隔上下内容的作用（旋转带的实际扫过范围见 pitfalls #16）。

```js
const BG="0E0D0C", PANEL="1C1A17", TEXT="F5EDDC", MUTED="A79C86", ACCENT="E3B341";
const SERIF="宋体", SANS="微软雅黑", LATIN="Georgia";
```

### 5. 荷兰风格派 De Stijl

**承诺**：眼前一亮——极度有序。用建筑般的精神把网格分成主次，颜色只留三个。
**SOURCE**：De Stijl 运动（荷兰，1917 年起，van Doesburg 与 Mondrian）：正交黑线、纯白底、红黄蓝三原色块。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `FFFFFF` | 纯白，占 65% |
| LINE | `141414` | 黑线/黑字：网格与外框 |
| RED | `C5312E` | 原色一 |
| BLUE | `1D5FA8` | 原色二 |
| YELLOW | `F2C500` | 原色三（要纯黄，不许偏橙金——偏了就滑向「黑金豪华」的金属感） |
| MUTED | `767676` | 次级文字 |

**字体**：`微软雅黑`（正文）+ `Arial Black`（编号/拉丁）
**字号**：主标 60 / 栏标 22 / 正文 15 / 脚注 12
**母题**：正交黑线分割版面（粗细有别：主分割 4pt，次分割 1.5pt），三个色块（红/蓝/黄各一）即三个内容区；色块文字黑白按对比定。
**BANNED**：任何第四个颜色、曲线、斜线、渐变、圆角、阴影——它全部不许。克制是魅力本身。

**用色纪律**（必守，色值可换）
- 角色数**严格 3 个原色 + 黑 + 白**，一个不多一个不少。这是这套风格的定义，不是偏好。
- 白底占 55–65%；三色块面积必须**不等**，最大的那块是主角（占三块总面积的一半以上）。
- 三块面积不等即层级：读图顺序由面积决定，不靠字号。
- 原色可以微调冷暖（红偏朱或偏正），但不能替换成非原色（不许粉、不许青）。
- 黑线只有两档粗细，不许第三档。

```js
const BG="FFFFFF", LINE="141414", RED="C5312E", BLUE="1D5FA8", YELLOW="F2C500", MUTED="767676";
const SANS="微软雅黑", DISP="Arial Black";
```

### 6. 苏联构成主义 Constructivism

**承诺**：眼前一亮——动员感。红黑白三色、对角线、粗大字块，像 1920 年代的海报在喊话。
**SOURCE**：俄苏构成主义（1920s，El Lissitzky / Rodchenko）：红黑白色、斜切块、蒙太奇、口号式大字。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `F0EDE6` | 纸白，占 60% |
| INK | `161616` | 黑：正文、粗线、反相黑块 |
| RED | `C33A2B` | 红旗红：唯一强调 |

**字体**：`黑体`（标题，粗重）+ `微软雅黑`（正文）+ `Arial Black`（编号）
**字号**：主标 62 / 副标 24 / 正文 15 / 脚注 12
**母题**：**对角线**（斜切色带、斜置编号「—01—」式）、大号红色口号块、黑白反相处。
**BANNED**：渐变、圆角、软阴影、多色（只剩红+黑+纸白）、居中小字——它要"冲"，不要"雅"。

**用色纪律**（必守，色值可换）
- 角色数 3：纸白底 + 纯黑 + **一个**红。不许第四个色相（次级灰只是 INK 降透明度，反相黑块直接复用 INK，都不是独立角色）。
- 纸白占 55–65%；红 ≤12%（比其他风格宽松，因为红本身是这套的表达主体）；黑承担粗字块与反相区。
- 红只用在两处：斜切带 + 编号/口号强调。**不许**同时给正文、边框、背景。
- 反相黑块必须承载真实内容（口号、大字），不许当纯装饰填空白。
- 斜切角度全页统一一个值，不许一页出现两个不同角度。

```js
const BG="F0EDE6", INK="161616", RED="C33A2B"; // 次级灰=INK 降透明度；黑块=INK
const HEI="黑体", SANS="微软雅黑", DISP="Arial Black";
```

### 7. 谷歌经典设计 Google Material 2014

**承诺**：居中——熟悉、易读、像可靠的产品界面本身。用户一眼就觉得"这是正经东西"。
**SOURCE**：Google Material Design 2014 首发规范（Google I/O 2014 发布）：4dp 栅格、高度层级（elevation 软阴影）、主/辅色、卡片、提示条。
**限定**：只用 **2014 版**。**BANNED：Material You 的一切**——动态取色粉彩、超大圆角（24dp+）、玻璃感。

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `FFFFFF` | 白场 |
| SURFACE | `F5F5F5` | 卡片/表面 |
| PRIMARY | `3F51B5` | 靛蓝 500：标题、主色块 |
| ACCENT | `FF4081` | 粉红 A200：唯一焦点（Material 2014 的辅色） |
| TEXT | `212121` | 正文 |
| MUTED | `757575` | 次级文字（54% 黑；更浅的灰在表面灰上读不出来） |

**字体**：`微软雅黑`（中文）+ `Segoe UI`（拉丁）—— Roboto 不是系统字体，写了会被替换，取形近的 Segoe UI 替代
**字号**：主标 48 / 卡标 18 / 正文 15 / 脚注 12
**母题**：8dp 增量栅格、卡片（2dp 半径、4dp 高度软阴影：半透明黑 30% 下偏 4pt）、一个主色块 + 一个辅色焦点。
**BANNED**：Material You 大圆角（radius > 0.06 英寸）、动态粉彩渐变、3D 吉祥物、发光。

**用色纪律**（必守，色值可换）
- 角色数 4：白底 + 表面灰 + **一个主色** + **一个辅色**。主辅各一个，这是 Material 2014 的核心规定。
- 白底 + 表面灰合计占 60–70%；主色 15–25%（App Bar 等结构件）；辅色 ≤8%，**全页只给一个焦点元素**。
- 主色可换成任意品牌色（靛蓝只是 2014 默认），但**辅色必须与主色形成明确反差**，不能是主色的近邻色。
- 次级文字用 54% 黑（约 `757575`），不要更浅 —— 浅灰压在表面灰上会读不出来（这条我在 Material 样板页上真犯过）。
- 这是全库**唯一**该用柔和阴影的风格：高度阴影是 2014 规范的核心语汇，此处用硬阴影才是错。

```js
const BG="FFFFFF", SURFACE="F5F5F5", PRIMARY="3F51B5", ACCENT="FF4081",
      TEXT="212121", MUTED="9E9E9E";
const SANS="微软雅黑", LATIN="Segoe UI";
```

## 五 · 版式结构（骨架，可与皮肤自由组合）

| 结构 | 怎么排 | 适合 | 翻车点 |
|---|---|---|---|
| **不等权分块**（Bento） | 大小不等的圆角格子铺满整页，一格一事 | 功能罗列、仪表盘、多要点并列 | 需要严格阅读顺序的论证会被拆碎；Bento 是 AI 高频，用户点名才用 |
| **瑞士栅格** | 严格栅格、全部左对齐、非对称平衡 | 专业严谨、方法论 | 栅格破一次整页就散 |
| **杂志编辑** | 大图 + 分栏正文 + 放大引文 + 图注 | 叙事、案例、品牌故事 | 正文一多就变读稿子 |
| **满幅图像** | 一张高质量大图铺满，文字压在暗化遮罩上 | 开场页、章节过渡、情绪铺垫 | 图不够好整页崩；文字必须加 60–80% 遮罩，禁止直接压图 |
| **单点聚焦** | 整页一句话或一个巨大数字 | 转折点、结论、震撼数据 | 放一句废话上去就毁了 |
| **数据仪表盘** | 多个图表 + 大号 KPI 数字卡 | 季度汇报、增长复盘 | 图表堆多了没有焦点 |
| **时间轴 / 流程链** | 编号步骤、连接线、里程碑 | 路线图、方法论、施工计划 | 步骤超五个就该拆页 |
| **左右对分** | 竖着对半切，左右对比或图文分立 | 前后对比、方案二选一 | 连续几页都这么排非常单调 |

### 图表与数据页纪律（配任何风格、任何预设都要守）

- **图题写结论，不写类型**：「迁移成本三年降 58%」在推进论证；「年度迁移成本柱状图」只是图的名牌。与判断句页标题同规。
- 直接标注优先于图例：系列 ≤3 时把数值 / 系列名直接标在图元上，省掉读者来回对照；系列多时才用图例。
- 柱状图基线必须从零开始；折线图纵轴不许用夸张截距造势——要截就注明，不注明就不截。
- 饼图 ≤5 块，从 12 点方向顺时针按大小排；超过 5 块改横向条形图。
- 每张图表标注单位与口径；数据来源不明就标「估算」，学术出版预设还要求关键数字带来源行。
- 图表内文字 ≥12pt（与图注同级）；网格线用最浅的 RULE 色，不跟数据抢。
- 图表配色遵守所在预设的用色纪律：多数预设只允许用主色的明度阶梯区分系列，不许引入新色相；学术出版要求灰度打印仍可分辨。
- 数据仪表盘页也守「唯一焦点」：让最大的 KPI 数字当主角，图表当配角——图表堆多了没有焦点。

## 六 · 页级编排规则（deck 级，多页必读）

单页好看容易，整份好看难。**"AI 感"的绝大部分来源不是单页丑，而是多页复读同一套骨架。**

### 6.1 每页必须有可指认且唯一的亮点

判断标准：**翻开这页，1 秒内眼睛落在一个元素上，且只有一个。** 任何风格（包括"舒服"型）都必须满足：

- 舒服型（和风、编辑、学术、Material）：亮点 = 大面积克制 + **唯一一个主角**（和风页的朱红主格就是那一个）。安静的页面里有一个方向性的焦点，正是"舒服"的构成。
- 眼前一亮型（粗野、构成主义、风格派、蓝图、黑色电影）：亮点 = 对比与冲击的一枚炸弹——但同样只留一个主角。
- **无焦点或平均分配 = AI 味**（深蓝科技的病理：青色洒满全场，满天都是重点 = 没有重点）。

### 6.2 页眉 / 页脚：克制，只准两种形态

- ✅ 页面顶部「小节名 + 页码 + 大标题」的纯文字组合、或 1px 细线分隔页眉与正文。
- ✅ 页脚只放小号来源/页脚说明。
- 🚫 全宽页脚色带、进度条、页眉色带、竖条，以及连续 ≥3 页的相同"角标+编号+当前/总页数"套件。

### 6.3 版式结构轮换

- 连续两页不得同版式；同结构 ≤ 全页数 1/5；卡片陈列 ≤ 1/5 且不连续。
- 10 页分配示例：单点聚焦封面 → 左右对分 → 时间轴 → 数据仪表盘 → 单点聚焦 → 不等权分块 → 杂志编辑……

### 6.4 强调色预算

每页最多一个焦点吃强调色；禁止编号、边框、小方块、正文颜色全用强调色。

### 6.5 视觉载体轮换

每页至少一个"非文字、非矩形"视觉元素：图片 / 图表 / 流程示意 / 大数字，四种交替，连用最多两页。讲流程就画流程图，讲数据就画图表——真正设计机会优先于通用装饰。

### 6.6 封面与结束页不为通用

封面禁止"眉标+标题+副标题+关键词"三件套；结束页不是封面镜像 +"谢谢"，要收束成一句话/三个要点/行动号召。
