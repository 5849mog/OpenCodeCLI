# 动效手法库（取材用）

## 这是什么，不是什么

**这是一本取材库，不是规范。** 它只收录「从零想不到、但确实高质量」的手法，供你在设计某一页时挑选或受启发。

- **不是必须遵守的模板。** 没有任何一条是"该做"的；不选它就对了，只要你自己的设计更好。
- **鼓励你按内容实时设计。** 手法要服务那一页的论证，不是反过来——先想清这页要观众看到什么顺序，再看库里有没有现成的说法。
- **不要为了用手法而堆动画。** 一页里能用一条好手法，胜过四条平庸的。本技能的默认倾向是克制：能不加就不加，要加就加在要害处。
- 每条都标了**依据**：菜单内的手法来自探针产物实测（`docs`/`ppt-design-selftest/anim_probe/`），菜单外的只有零星采样，用它们属于 `--raw` 逃生舱、**须用户明确同意**，且交付时要声明 `[降级]`（见 `pitfalls.md` #32）。

播放体验的底线（不是手法，是纪律，写在 `SKILL.md` 步骤 10）：**页内全自动连播，断点只在翻页。**

## 一、菜单内手法（有权威依据，可被逐条验证）

### 1. 物体连续性：同名形状跨页 morph
- **适用**：章节推进；同一个母题元素要贯穿两页（一个色块从角落走到中央、一张图从缩略变成主角）。
- **好在哪**：这是唯一能表达「**同一件事在变化**」的手法。观众感到的是连续，而不是"又换了一页"。
- **怎么落地**：相邻两页给那个元素**同一个 `objectName`**，切换用 `平滑`（morph）；其余不需要连续的元素保持各自命名，会自动淡入。
- **注意**：qa 会点名「本页独有 / 上页独有」的形状清单——那是给你确认"这个元素我是不是本来就打算让它淡入"。删掉不配对的形状名不是目的，**想清楚哪些该连续**才是。
- **依据**：`probe_trans_auth.pptx`（`p159:morph option="byObject"`、`p14:dur="2000"`，EntryEffect 3954）。

### 2. 翻页无缝：切换与页内首条同时起播
- **适用**：任何带动画的投屏 deck，morph 页尤其。
- **好在哪**：消除"翻页 → 静止一下 → 开始动"的顿挫。观众感觉是"翻过去，画面自己开始讲"。
- **怎么落地**：页内首条一律 `触发: "自动"`；切换也用默认（切换本身随翻页播放）。**别在这里加点击**——那会让无缝断掉。
- **依据**：注入器默认行为（`p:transition p14:dur` = 切换播放时长，与换片计时无关，见 `pitfalls.md` #33）。

### 3. 节拍揭示：擦入自左侧做推进
- **适用**：图表逐系列出现、流程/时间轴按顺序推进、步骤类内容。
- **好在哪**：**方向自带语义**——从左往右擦入读作"进展"，比淡入（只表示"出现了"）多点信息。整页只用一个方向，不要左右混。
- **怎么落地**：`{"效果": "擦入", "方向": "自左侧", "触发": "之后"}`，时长 0.5–0.8s。图表按系列顺序、每条一个。
- **依据**：`probe_auth.py` / `_probe_wipe.py` 实测（`wipe(dir=l)`；擦除的左右编码与推入相反，见 `inject_anim.py:179`）。

### 4. 阶梯：浮入自底部做列表
- **适用**：要点列表、层级从属的内容。
- **好在哪**：视线自然从上往下跟；"自底部上浮"给人的感觉是"落地"，比淡入稳。
- **怎么落地**：`{"效果": "浮入", "方向": "自底部", "触发": "之后"}`，默认 0.8s，逐条接续。整条阶梯总时长控制在 8s 内（qa 有阈值）。
- **依据**：`probe_auth.pptx`（enum 39 → `presetID=42`，`presetSubtype=0`，上浮）。

### 5. 从局部展开：缩放
- **适用**：一个元素从"小"变成主角——图标长成整块、局部放大成全幅、细节展开成全局。
- **好在哪**：表达了**因果或尺度关系**（小东西变成大东西），而淡入只能表达"出现了"。
- **怎么落地**：`{"效果": "缩放", "触发": "自动"}`（presetID 53 / subtype 16）。一页最多一次，它太抢。
- **依据**：`probe_auth.pptx`（enum 48 → `presetID=53 presetSubtype=16`）。

### 6. 钉住落点：强调-放大
- **适用**：结论数字、关键判断——配合"数字最后落点"的论证节奏。
- **好在哪**：**不改变布局**就能把注意力按在一处（脉冲放大后自动回位，`autoRev="1"`）。这是"指出来"而不是"再放一个东西上去"。
- **怎么落地**：`{"效果": "强调-放大", "触发": "之后"}`（presetID 6，可给 `幅度`，默认 1.5）。**一页只用一次**，且这一页不要再有别的强调色焦点（强调预算）。
- **依据**：`probe_auth.pptx`（pid 6，`p:animScale` + `autoRev="1"`）。

### 7. 静默换场：只有切换、没有页内动画
- **适用**：满幅图页、一句话大字页、需要观众先读完再说的页。
- **好在哪**：**节奏要有强弱**。如果每页都在动，等于每页都没有焦点；留几页"只是翻过去"，前面那些动效才显得有意图。
- **怎么落地**：`transitions` 里给这一页，`pages` 里不写它。
- **依据**：机制层面无需依据（不注入 anything）。

### 8. 时长梯度：让主次可听可见
- **适用**：任何一页有多条动画的时候。
- **好在哪**：所有元素一样慢 = 没有主次，观众找不到先看哪个。
- **怎么落地**：主角 0.8–1.2s，配角 0.4–0.6s，切换 0.7–0.9s（都在菜单默认值附近，不用刻意写 `时长`）。单条不短于 0.3s（qa 会对 <0.2s 告警）、不长于 2s。
- **依据**：菜单默认时长表（`inject_anim.py` 的 EFFECTS / TRANSITIONS）。

## 二、菜单外手法（须 `--raw` + 用户明确同意，交付声明 `[降级]`）

**先读 `pitfalls.md` #32。** 这些手法没有逐条断言可做：注入器只验证「文件能打开 + 读回条数」。只有当用户明确要求、且明确同意之后才用，并且一次只放行必要的那几页。

### 9. 沿路径移动（`p:animMotion`）
- **适用**：表达"经过"或"迁移"——一个点沿曲线走到终点、货物流转、时间轴上的位移。
- **好在哪**：路径本身承载信息（怎么走的），位置插值做不到这一点。
- **依据**：`probe_auth.pptx` 里有 1 处现场采样（enum 47）：
  `<p:animMotion origin="layout" path="M -0.46736 0.92887 C …" pathEditMode="relative" ptsTypes="">`，其内层 `cTn` 带 `decel="50000"`。
- **警告**：**单次采样、未做往返验证**。用之前建议先跑一轮探针把目标效果的编码取全。

### 10. 旋转（`p:animRot`）
- **适用**：有旋转语义的母题（齿轮、指针、风车）；或"转正"一个刻意歪斜的元素。
- **好在哪**：旋转是唯一能表达"周期/角度"的运动。
- **依据**：`probe_auth.pptx` 里有 2 处现场采样：`<p:animRot by="21600000">`，`by` 单位是 1/60000 度（21600000 = 360°）；同 par 的 `attrName` 为 `r`。
- **警告**：同样只有零星采样、未往返验证。别把"转一圈"当成转场噱头——本技能的取向不允许。

## 三、暂未收录（没有依据，别凭想象写）

- **逐段落揭示（`p:bldP` / 按级别）**：让一段多行文字按段落逐条出现，而不是整块飞入。这是文字讲义页的真实需求，但**探针从未覆盖它**，本库拿不出权威 XML。真要做，先新开一轮 COM 探针取采样，再考虑进菜单；在拿到依据之前不要手写。
- **图表按系列/按类别构建（`p:bldGraphic`）**：同上，无采样。当前替代做法是把图表拆成多个形状各配一条擦入（见手法 3），或者接受整块淡入。
