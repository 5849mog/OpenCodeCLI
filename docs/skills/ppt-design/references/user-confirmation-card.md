# 用户方向确认卡

这是**唯一默认发给用户确认的方案**。目标是用户在 30–60 秒内确认方向；不要把
字号、色值、锚点名、QA 阈值、图标 JSON 或动画 XML 展示给非专业用户。

```markdown
## PPT 方向确认卡（请确认）

### 这份 PPT 想让人记住什么
**核心结论**：<一句可被接受或反驳的判断，不是主题名>

### 给谁看、用在哪
<受众> · <投屏/自读/打印> · <页数或时长>

### 它会长什么样
<1–2 句大白话：主色、视觉意象、想给人的感受；不写术语>

### 页面会怎么推进
- P1：<立论>
- P2：<举证>
- …
- Pn：<收束>

### 演讲与动画
<现场讲/自读/打印>；<不加动画，或每页几组、需点击几次>；<不会自动翻页>

### 素材与不能碰的边界
<用户素材如何处理、品牌/事实/标题哪些不改；没有则写“无”>

### 请只确认这三件事
- [ ] 这句话和推进顺序是我想表达的；
- [ ] 视觉方向符合场合；
- [ ] 可以先制作 <P2/样板页>。

要调整时，请直接说“改结论 / 改风格 / 改节奏 / 改边界”。
```

## 何时展示详细施工单

只在用户明确要求详细方案，或涉及品牌审批、合规、版权、素材处理、动画技术要求、
多人交接时展示。确认卡通过后，AI 在内部生成完整施工单，具体字段见
`references/internal-build-spec.md`。
