# 高级能力增量流程

只在任务触发时加载；先完成标准或最小流程。

| 触发 | 必读 / 必跑 | 不可省略的约束 |
|---|---|---|
| 用户图片、扫描件 | `prep_assets.py` 文件头；先清点再处理 | 未确认不得改素材；扫描件默认清洗优先。 |
| 公式 | `inject_math.py` 文件头 | `$$...$$` 独占文本框；先注公式再注动画。 |
| 函数/几何图 | `inject_figure.py` 文件头 | 先写作图依据；约束验算失败不写文件。 |
| 图标 | `inject_icons.py` 文件头 | 单色、每页 ≤3、锚点名唯一。 |
| 动画/切换 | `inject_anim.py` 文件头、`anim-atlas.md` | 先看 `doctor`；无 COM 时不得声称逐条验证；不写自动换片。 |
| 模板填充/小修 | `pptx-core/SKILL.md` 的模板/编辑章节 | 不走重设计流程，除非用户要求整体换风格。 |

原始 XML 动画只能在用户明确同意时使用 `--raw`；没有覆盖全页的断言清单时必须按降级交付。
