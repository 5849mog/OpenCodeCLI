# `printf` 能力测试报告（纯 JS 实现）

> 针对模拟 Bash 新增的 `printf` 命令（bash 内建语义，纯 JS）的能力验证矩阵。
> 背景：原仅有 `echo -e` 做简单格式化；printf 支持转换符、标志、宽度/精度、转义、`\c` 截断，且**不自动追加换行**。
> 实测：tsx 直连 `toolBash`（与应用内 `/run` 同一条代码路径）逐条断言；「实际结果」列 ⏳ 的行请在浏览器 http://localhost:3000 用 `/run` 复核。

## 测试结论

- **全部 40 项已测能力通过**（tsx 直连 `toolBash`，与应用内 `/run` 同一代码路径；#40 需浏览器复核）。
- **与真实 bash 的已知分歧**（刻意，文档已注明）：
  1. 多余参数**忽略**（真实 bash 复用格式串消费完所有参数）；
  2. `toFixed` 为 round-half-to-even，真实 printf 为 round-half-away-from-zero（如 `%.0f` 的 2.5）；
  3. `'` 千分位标志解析时跳过、不应用分组；
  4. 未知转换符（`%z`）原样输出该字符而非报错。
- **回归**：`echo`（含 `-e`）与既有命令行为无变化；`awk.ts` 的 `sprintfAwk` 未改动（awk 降级路径不受影响）。
