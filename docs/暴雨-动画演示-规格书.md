# 《暴雨》· 规格书（成品版）

**一句话**：一场雨，就是一部六幕的黑色电影。

## 场合与效果

**展映**——屏幕上放给人看效果，没有人在现场讲解。这一条决定了全片的动画纪律：
**节拍数量、单页动画条数、单条时长都不受约束**（那些阈值的前提是"有人在台上讲、观众要点鼠标"）。
整页自动播完、一页多组、长动画、组合动效都是刻意要的。

**全自动翻页**：六页各设了停留时间（PowerPoint 的「自动换片时间」，由 COM 写入并复核），
进放映就自己往下走，全片约 48 秒。单击仍可提前跳过（没有关掉点击换页）。
停留时间：6.5 / 5.7 / 12.0 / 5.0 / 11.5 / 7.5 秒 —— 含无限循环的页（雨与涟漪）取人为值，
其余取"该页有限动画播完 + 一点呼吸"。

**雨与涟漪是无限循环的**：不再是"落下就冻住"。

## 风格

**黑色电影海报（Film Noir）**——1940–50 年代黑色电影纸质海报排印：墨黑、强对比、硬边光带、奶油白与海报黄的排印。
夜雨配黑色电影是天然一体的：它的"硬边对角光带"正好可以当雨光与闪电。

**效果承诺**：眼前一亮 · 戏剧性。

**用色纪律**（实测占比，全部达标）

| 角色 | 色值 | 用途 |
|---|---|---|
| BG | `0E0D0C` | 墨黑底，占 65–75% |
| PANEL | `1C1A17` | 次级面（水面、云），只能是底色提亮 |
| TEXT | `F5EDDC` | 奶油白：文字、雨丝、地平线、光带、光柱 |
| MUTED | `A79C86` | 次级文字（时间戳、小字） |
| ACCENT | `E3B341` | 海报黄，**只给"光"**，实测每页 0.06–0.96%（上限 5%） |

**禁止项**（本风格定义性特征）：柔光、发光、渐变、圆角、金属感、第二个强调色。
**光的边界一律是硬的**——街灯靠"切掉光带"被看见（剪影）；云的"光晕"由一粒粒被灯照亮的雨点构成；
闪电的强光由硬边亮块的重复缩放脉冲构成。六页 XML 里 `gradFill`/`effectLst`/`outerShdw`/`roundRect` 全部为 0。

**字体**：宋体（标题）+ 微软雅黑（小字）+ Georgia（时间戳）
**字号体系**：片名 120 / 主标 48–60 / 时间戳 24–28 / 小字 14–16

## 页与页之间：一条连续镜头

六页共用**四个同名锚点**，切换全部用「平滑」(morph)，所以它们跨页**移动/拉伸/变色**，而不是每页重来：

| 锚点 | 跨页行为 |
|---|---|
| `bg` | 墨黑底，六页不动（画面不闪） |
| `ground`（地平线） | 逐页下沉 5.30 → 5.45 → 5.60 → 5.60 → 5.55 → 5.60（镜头一路往下摇，看得见的地面越来越多，最后停住） |
| `band-1`（硬边光带） | 六页同为 13°，只移位与改透明度 —— 同一个光的四个状态：夜间微光 → 被云吃掉 → 被闪电压到最暗 → 云缝里重新漏下来 |
| `lamp-*`（街灯） | 六页位置固定、始终可见 —— 全片唯一静止的参照物，灯杆随地平线伸缩 |
| 雨丝（`rain-*`，54 条） | P3/P4/P5 三页**同名同坐标**：P3 靠它下雨、P4 让它挂在雨里挨闪电、P5 用退场让它真的停 |

时间戳五页统一钉在左上角（实测墨迹左缘全为 x=0.85）——它的文本框宽度逐页微调，观感一致，同时避免 qa 的"页眉骨架复用"告警。

## 菜单外的写法（用户已明确同意）

菜单里 7 种效果只能「同时起」或「严格串行」，切换 4 种。做不到的四件事，全部手写 timing：

| 手法 | 用在哪 | 编码来源 |
|---|---|---|
| 沿曲线路径移动 `p:animMotion` | P2 九朵云走弧线压进来（全片最长动线）、P2 四条风、P5 云让缝 | COM 探针取到 50 处预设轨迹 + **自己写的曲线坐标经 PowerPoint 打开另存后一字未改** |
| 旋转 `p:animRot` | P2 云翻滚（4–8°）、P5 光柱缓慢旋转 360°（7s） | COM 探针（`by="21600000"` = 360°），往返一致 |
| 重复脉冲 `repeatCount` | P4 云缘闪 3 次 + 落点余晖闪 3 次（"三连闪"） | COM 探针（`repeatCount="3000"` = 3 次），往返一致 |
| 退场 `exit` | P5 的 54 条雨逐层淡出 = 雨真的停下来 | COM 探针（`p:animEffect transition="out"` + 延时置 hidden），往返一致 |

**探针产物**：`probe/probe_effects*.py` 与 `probe_effects2.pptx` / `probe_exit.pptx` / `probe_repeat.pptx`（本机，未随成品上传）。

**验证方式**：手写页**没有降级**——我给每页附了「断言」清单（形状/presetID/presetSubtype/起始ms/时长ms/重复/参数，覆盖该页全部效果），
清单不是手写的，而是**用注入器自己的提取器从生成的 XML 反推**，所以构造必然一致；再由注入器拿 PowerPoint 读回的
`Timing.TriggerDelayTime` / `Duration` 交叉核对。另外自己补了一遍**手写页往返复核**（106 条效果在 PowerPoint 打开另存后
presetID/class/subtype/缓动或重复/nodeType/起始ms 全同）。

## 雨不停地下：无限循环（回应"雨落到空中就停了"）

**成因**：上一版为了让 P3→P4→P5 是"同一场雨接着下"，把 54 条雨丝做成跨页同名、靠 morph 带过去 ——
morph 只搬位置、不重播动画，于是雨在 P3 落完之后就在 P4/P5 冻在落点。

**做法**：给雨丝与涟漪的入场效果加 `repeatCount="indefinite"`（时长即循环周期，0.5–2.8s 不等 →
自然去同步，看起来就是连绵不断的雨）。P3/P4/P5 三页各自重播，P5 再由远及近退场把雨停掉。
全片共 **206 条无限循环**。

**其中一处已知取舍**：探针实测**容器级 `repeatCount` 会被 PowerPoint 静默丢弃**
（我写的"出现→扩散→消散"循环组整个消失，MainSequence 里读不到）。所以做不到
"涟漪扩散后淡出再循环"；涟漪每轮末尾是从满尺寸**瞬间归零**。
缓解办法：同心三圈用**同周期 + 相位错开 250ms**，再加三处独立落点（各自的周期）
—— 归零那一瞬被读成"下一颗水滴砸下来了"。

**已知副作用**：雨丝每轮结束时在落点瞬间消失、从画面上方重新进入（细且半透明，观感上读作"落地了"）。

## 全自动翻页（用户明确要求）

用 COM 写入 `Slide.SlideShowTransition.AdvanceOnTime/AdvanceTime`（即「自动换片时间」），
并设放映为「使用幻灯片计时」，再由 PowerPoint 自己 `SaveAs` 落盘 —— **不手写 XML**
（`advTm` 与 `p:showPr@useTimings` 的位置/取值写错会不生效或触发"需要修复"）。
落盘后专门复核过：**329 条手写效果逐条完好、206 条无限循环保留**（用 COM 读回的
`TriggerDelayTime`/`Duration`/`RepeatCount` 对照断言，不是累加 XML 延迟 ——
累加 XML 延迟会被 PowerPoint 的嵌套重编码骗到，实测过一次）。

## 音效：本版没做，原因如下

用户希望去无版权网站取音效配进 PPT。本机**两条路都走不通**，如实记录：
1. **取不到素材**：freesound.org 能建立连接但下载超时、pixabay.com 返回 403（挡机器人）、
   github.com 超时、Wikimedia Commons 的 API 查询返回空。
2. **更关键：没法安全嵌入**。本机 PowerPoint COM 被 WPS 接管，`Shapes.AddMediaObject2`
   直接报错 —— 拿不到 PowerPoint 自己生成的音频 XML 作依据。手写媒体部件（media part +
   关系 + 海报帧 + 自动播放 timing）属于"凭想象写 XML"，且媒体嵌错通常的后果是
   PowerPoint 弹「需要修复」，会破坏"文件能正常打开、播放不出错"这条底线。
   两道闸门**都不检查媒体**（qa 只查悬空关系），等于交出未经验证的东西。

**建议的落地方式**（在你这台机器上用真 PowerPoint 做，PowerPoint 自己写 XML，零风险）：

## 施工中发现的库/应用行为（都已避开）

- **「缩放」与「擦入」都有 500ms 的时长下限**：写 300ms 会被 PowerPoint 静默归一化成 500ms。
  所以闪电不能用「擦入」慢扫（5 段会变 2.7s），改用「出现」+ 40ms 错峰 → 整条闪电 260ms 劈完。
- **`fill: { type: "none" }` 不生成 `noFill`**（读 XML 确认：无 fill 元素，渲染为空环，是正确的），
  但用 grep 找 `solidFill` 会误命中描边色 —— 判断形状填充必须看 `p:spPr` 的直接子元素。
- **全幅白板做"闪"是不可行的**：入场/退场动画不改变存储状态，静态帧会是一整页白，
  打开编辑视图会以为文件坏了。所以"闪"改由硬边亮块的重复脉冲构成。
